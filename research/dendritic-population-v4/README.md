## 需要一起确认的修订

1. **A 补配对 SPSA 重跑。** 同一批新数据、同初始化、同 CE、同固定学习率下比较训练方法，不能拿新 Adam 的 RATE 最佳结果对比历史 V2 的 CE 失败。保留请求的 CE/RATE 搜索作为另列的配置实验。结论仅限该任务、方法、预算和种子，不写“历史失败唯一由 SPSA 导致”。
2. **阶梯不是每次严格只改一个因素。** 在保持 V2/V3 端点、24 步序列和读出窗口的前提下，上述短脉冲设置不可避免地改变了 L0→L1 的位置/持续时长；L3 也改变线索和目标规则。草案逐项说明，没有声称单因素难度因果分解。
3. **测试资格需选择一个解释。** 草案默认严格执行“失败配置不测”：可以做通过模型的新测试，但无法满足“通过与失败两方的测试配对差异”。若希望检验第 4.3 节，需批准一个窄例外：至少一方通过时，让预先锁定的失败方作为对照一起接受同一次测试，不再选模。双方均失败不测；双方每个种子均 ≥99% 时仍不测。
4. **C 结论限定预算。** 无跨细胞重训失败，只说明在规定训练预算内未找到替代解，不证明数学上的必要性。遮蔽 60 个权重后，实际可学习参数是 116，不能仍记为 176；两个结构的消融臂彼此保持相等。
5. **“新测试 seed”建议同时包含新初始化和新输入。** 先固定配置，在 5 个新的训练种子上重新训练并提交检查点，再生成新测试输入；不筛掉表现差的复制种子。额外训练计入成本。若只需新输入样本，可减少计算，但不能称为新训练种子复现。
