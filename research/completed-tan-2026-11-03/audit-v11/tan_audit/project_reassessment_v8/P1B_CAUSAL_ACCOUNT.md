# Consolidated P1B diagnosis

2026-11-02. This is a synthesis of completed evidence, not an additional fit or a new confirmatory label. Frozen repository: `85213f0d417d54e4f48b301ed1c0e4200ef3c421`.

P1B fails as a particular sequence of input transformation, state evolution, query transduction and output decoding. The evidence does not identify one universal cause, and the stages' contributions cannot be added as percentages of explained failure. Some input histories are already indistinguishable at the registered ports; others remain distinguishable there but are not reliably delivered by the tested carrier and readout. The later external probe shows that a little predictive information survives, without demonstrating usable key binding.

## One causal chain, with the evidence strength at each link

1. **The declared task and model access differ from the evaluator's records.** The runner retains keys, values, positions and targets; M0 explicitly queries a key/value buffer. M1 receives the temporal content/novelty/query drives and evolves `(u,A,r)`. The evaluator's raw records are not available to the native decoder. Source: frozen `p1_experiments/p1b/models_p1b_v2.py`, `runner_p1b.py`, Protocol V2.6 §§2–5. This access distinction is a source fact, not an inferred biological limit.

2. **Input transformation causes exact ambiguity on part of the task domain.** The native event ports are `c=k+v` and `nu=max(0,abs(k)-1.4)`. With positive keys and positive novelty, `k=nu+1.4` and `v=c-k`: there is no ideal event-input collision in that stratum. With multiple low-key events, matched complete port histories can request different target values. A positive primer leaves A active during both ambiguous events, so this example is stronger than initial-zero-gate erasure while still relying on the rectified key region. This is an exact constructed-pair obstruction, not a measured population prevalence. Source and complete-path verification: [interface reassessment](../interface_reassessment/REPORT.md) and [scope correction](../interface_reassessment/SCOPE_CORRECTION.md). V2.6 had already anticipated first-event erasure; that earlier fact is not a new discovery.

3. **The carrier is not established as a sufficient variable-key memory even where the input is informative.** The registered G1.5 fixture shows an ideal affine state fiber on a fixed-key, subthreshold branch with fixture-specific content weights .1; it must not be relabeled as a universal full-task theorem. The unchanged-M1 novelty-stratified replay still fails in the all-positive subset, and its six whole-cell outcomes match the historical M1 summary. Those facts show that rectified-port ambiguity alone cannot explain all observed failure. They do not locate the remaining failure solely inside state compression. Source: Protocol V2.6 §8.1; [stratified replay](../interface_reassessment/REPORT.md).

4. **Native query dynamics have an exact access restriction.** During a query, content current is zero. Holding cue-onset u,r and q fixed, changing A cannot change the subsequent u/r trajectory, spike sequence or native readout. A can already have affected u during encoding, so this is not a statement that A never matters. The one-step code and 96 independently checked A-intervention checkpoints establish this restriction. Source: model lines 221–269 and [stage localization](../stage_localization/REPORT.md).

5. **The frozen output policies impose further limits.** Analog decoding is one frozen affine function of the deadline candidate/reset value, with no direct q argument. Spike decoders use only eligible cue steps 1–99; silence is an abstention with zero scoring fallback. The exact Ecomp identity is `max(|eA|,|eB|)`. Native count/latency support calculations explain why the original .05 mean-error goal is unattainable for those clean output alphabets even for an otherwise privileged choice of output. These are output-contract bounds, not demonstrations that discretization is the sole practical bottleneck. Source: [native support audit](../floors/native_support_recheck/), frozen model lines 249–303 and Protocol §§5,7.

6. **External decoding reveals limited residual prediction, not repaired retrieval.** With original M1, disjoint histories and fixed degree-four ridge probes, full endpoint plus q gives test Ecomp 1.890126 versus native 1.977919, query-only 1.976712 and shuffled-state 1.977327. Strict joint accuracy is only 4.13%. The all-positive subset also improves modestly but remains poor. This rejects a blanket assertion that every endpoint contains no target-predictive information. It does not establish query-specific selection, an optimal decoder, carrier sufficiency or neuronal implementability; shared content statistics can explain some gain. Unequal feature capacities and direct state/q access prevent unique causal assignment of the gain to A. Source: [stage-localization protocol, ledgers and review](../stage_localization/REPORT.md).

## What the enriched controls do and do not add

The supplied three-timescale experiment shows that selectively longer gate retention improves a *modified*, known-key, narrow-domain inverse under extra analog observation. It also changes normalized forcing, amplitudes and costs. It does not isolate original M1's decay constant as the sole failure mechanism. Ideal interpolation, precision and finite-write controls show that other explicitly enriched algorithms can perform two-item binding under different ports, arithmetic, phase control and retention. They are resource comparisons, not repairs to historical P1B or evidence that any fixed state count is biologically equivalent.

## Decision

Keep all original `FLOOR_LIMITED_COMPARISON` and channel-limitation labels. Correct manuscript/code-contract mismatches with the existing Unapplied patches; do not rewrite failures as successful memory. Close the present P1B decoder exploration: a larger fitted decoder might improve a score without resolving the original mechanistic question. Future P1B work needs a named contract-level hypothesis—input identifiability, online binding or physically accessible query/readout—not an unbounded search for a better external inverse.

The next independent check returns to original TAN-I: whether a task-relevant target can remain in its explicit ordered window yet become unavailable through the complete allowed Probe1 response. This distinguishes full-state storage from observable recovery and uses an exact original-model intervention instead of another decoder variation.
