## Mechanism and resources

At first active-event onset store(k1,v1) in two real registers. At the second onset compute a=(v2-v1)/(k2-k1),b=v1-a*k1 and overwrite the registers with(a,b). Subsequent queries get only q and the two stored numbers, producing a*q+b; no keys, positions, target IDs or history go to the query decoder. Persistent controller phase has three states empty/one/ready: explicitly budget a finite-state controller requiring2binarybits, plus external event-onset strobes, trialreset and encoding/readout clock. No claim that original randomslot masks alone supply the phase. The current input(k2,v2), arithmetic temporaries, subtraction/division/multiplication/addition, instantaneous atomic overwrite and ideal real-valued output are explicit resources. Write value/key arguments are data arriving online, not evaluator targets. No biophysical implementation, original-TAN equivalence or N=3 result is claimed.

Pre-execution resource clarification from independent review: the writer receives separate raw key and value inputports. Native TAN's neuronal interface instead uses summed content(k+v) and keynoveltymax(0,k-1.4), which cannot recover both inputs for lowkeys. TaskGenerator exposing rawarrays to the simulator does not make them native neuronal ports. This explicit input-interface change is granted equally to interpolation and M0, and must be counted alongside nonlinearwrite/phase/readout changes. It preserves the task's incoming semantic eventpairs but changes the implementable circuit interface.

Raw register interpretation changes with phase. Fixed post-encoding fullscales are |a|<=120 and|b|<=297; the same raw register ranges cover first-record k,v, with inefficient use of range before the transform. Initial/event-write perturbations are absent except the explicitly labeled write-key condition. No analog precision/energy equivalence is inferred from two coordinates. A fixed centered alternative a*(q-1.4)+d,d=b+1.4a can analytically reduce |d| to129; do not add it as another fitted/tested arm. Noise costs depend on coordinates, not state count alone.
