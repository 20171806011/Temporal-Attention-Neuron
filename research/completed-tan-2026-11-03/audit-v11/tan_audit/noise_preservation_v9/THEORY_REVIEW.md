# Task B signal-preservation review

Date: 2026-11-02. Independent source and mathematical review for the v9 study. Repository commit: `85213f0d417d54e4f48b301ed1c0e4200ef3c421`. This review did not execute new neuron trajectories, fit thresholds, or inspect new diagnostic outcomes. Suggestions below are prospective; the main study's frozen protocol determines its actual tests.

## What the original endpoint measures

The frozen Task B input is 15 zeros followed by 45 samples at amplitude 1.5, with independent Gaussian noise of standard deviation .4 added before clipping the entire input below at zero. The scored output is

`R(y) = sum(y[20:60])/40`.

The native comparison uses LIF with leak .8 and threshold 2, versus TAN with window 10, leak .8, threshold 1, no dead zone, signed surprise, and the gate `tanh(abs(S))`. It is not the rectified window-5 model used in other analyses. Both native models receive the same noise for the same seed. Source: [Task B generator, parameters, and endpoint](https://github.com/20171806011/Temporal-Attention-Neuron/blob/85213f0d417d54e4f48b301ed1c0e4200ef3c421/snapshot/code/experiments/statistical_validation.py#L174-L201); [native update equations](https://github.com/20171806011/Temporal-Attention-Neuron/blob/85213f0d417d54e4f48b301ed1c0e4200ef3c421/snapshot/code/experiments/statistical_validation.py#L73-L132).

For binary spikes, `0 <= R <= 1`, and every output silent in indices 20 through 59 attains the exact global minimum zero. An always-silent neuron attains that minimum while carrying no information about the step. More generally, any output deletion rule cannot increase R. The objective contains no penalty for missing the onset, because indices 15 through 19 are excluded. This is a mathematical limitation of interpreting the endpoint alone, not evidence that native TAN actually has no useful response.

The code supplies an implicit policy that plateau spikes are unwanted, but no ground-truth spike train, trial-by-trial noise attribution, or event-versus-catch detection endpoint. Calling the score a false-spike rate can describe that policy; calling every counted spike *noise caused* is not established. Under a change-detection interpretation, useful signal means a preserved response to the amplitude transition, with relatively little response to an otherwise identical no-step input. Under an amplitude-coding interpretation, discarding the plateau could instead discard useful signal. The project must state which objective it means. This study should use the former, source-consistent onset interpretation without claiming recovery of arbitrary clean waveforms.

## Exact clean-input certificates

For clean LIF, the zero initial state stays zero before index 15. After the step, the first two candidate voltages are `1.5` and `.8*1.5+1.5=2.7`; the second crosses threshold 2 and resets to zero. Thus spikes occur at indices `16,18,...,58`. There are 22 spikes in the full trajectory and exactly 20 spikes in `20:60`, giving **R = .5 with no injected noise**. This follows directly from the frozen recurrence and strict `>` threshold; it is not a numerical trajectory result. It demonstrates that the original endpoint counts clean stimulus-driven LIF spikes as well as any noise-dependent activity.

For clean TAN, the rolling window first becomes entirely 1.5 at index 24, the tenth post-onset sample. From then on, `S=0`, the gate and attention current are zero, and the post-threshold state decays without generating further spikes. Its state after any update is nonnegative and at most its threshold, because a crossing resets it. Therefore the original `20:60` interval contains four possible clean adaptation samples, indices 20–23, before full window filling. A measured clean TAN score must be retained as a transient component, not silently called noise. No exact clean TAN spike count is claimed here.

Clipping also matters: the injected Gaussian noise is zero-mean, but the no-step input `max(noise,0)` is not. Its population mean is `.4/sqrt(2*pi)`, approximately .1596. A no-step control must preserve the original clipping and noise sequence; replacing it with signed or zero input would change the background statistics.

## Minimal controls and interpretations

The smallest useful extension preserves native parameters, input amplitude, noise, duration, initialization, and spike outputs. Reproduce original seeds and their original plateau endpoint first. Add only a no-step catch using the same per-seed Gaussian sequence and clipping, plus deterministic clean step/no-step controls. Freeze one onset window before running; the original excluded transition window `[15,20)` is particularly directly connected to the existing endpoint. A window based on TAN's W=10 would be a defensible alternative but must not be selected after comparing outcomes.

Use a prespecified scalar onset count and a fixed any-spike decision, reporting step sensitivity, catch false alarms, and balanced accuracy. A threshold-free rank discrimination statistic can supplement these. For scores `s+` and `s-`, ordinary population AUC is `P(s+ > s-) + .5*P(s+ = s-)` for independently drawn step and catch trials. This is standard rank-based discrimination, not new information theory or a novel TAN metric. [Hanley and McNeil (1982), original methodological article](https://pubmed.ncbi.nlm.nih.gov/7063747/).

Same-noise paired superiority instead estimates `P(s+(epsilon)>s-(epsilon)) + .5*P(equal)`. It can be useful as a paired intervention diagnostic, but is not ordinary population AUC. For a clean estimate of independent-trial rank discrimination with paired simulated classes, cross-seed comparisons `i != j` avoid same-noise diagonal pairs. Alternatively report the usual empirical all-pairs AUC and disclose the paired diagonal contribution. Resample entire independent seed blocks for uncertainty, preserving both classes and all model outputs; time bins are not independent replications. Do not choose the score direction or decision threshold from test outcomes.

Mandatory zero-output control: R=0, onset sensitivity=0, catch false-alarm rate=0, balanced accuracy=.5 on balanced classes, and AUC=.5. It certifies that the original endpoint alone rewards complete suppression. A constant always-spike control also has AUC=.5 but R=1. If native TAN retains onset discrimination, that is meaningful positive evidence even if another native model has similar discrimination; lower plateau rate can then be reported alongside that preserved function. If TAN loses detection, its lower R is compatible with gain collapse. Either outcome leaves the historical Task B numerical result and label untouched.

## What a matched budget can and cannot establish

Threshold 2 versus threshold 1, different effective currents, and a stored window/softmax do not constitute gain matching. Threshold or gain tuning after noisy outcomes would create a new optimized comparison. If a gain control is indispensable, freeze a calibration using only the clean original stimulus and report the changed gain and resulting clean response explicitly. A cleaner optional diagnostic is an output thinning/surrogate control with an independently frozen rule, but it must preserve class blindness and avoid matching separately using true labels.

Equal expected spike count is only an output-event budget. Matching realized counts per history can itself use future information, and shuffling each class's times preserves class information in total counts; such a control cannot be described as signal free. Any such control should say precisely which timing or amplitude information it removes. Neither spike-count matching nor the integral of a dimensionless internal current establishes equal hardware energy, metabolic cost, or noise exposure.

The manuscript already states that TAN's extra internal computation prevents a net energy claim without measurements: [limitations, energy](https://github.com/20171806011/Temporal-Attention-Neuron/blob/85213f0d417d54e4f48b301ed1c0e4200ef3c421/snapshot/manuscript/sections/conclusion.tex#L25). An experimental primary precedent measures information transmission together with costs from postsynaptic ion pumping and action potentials; simply suppressing outputs is not its efficiency criterion. This motivates the distinction, without transferring its biological numbers to TAN. [Harris et al. (2015), Energy-Efficient Information Transfer by Visual Pathway Synapses](https://pmc.ncbi.nlm.nih.gov/articles/PMC4691239/).

## Manuscript scope and the separate MI agenda

The manuscript reports original Task B rates LIF `.506 +/- .026` and TAN `.265 +/- .034`, describes a 48% reduction, and labels the comparison PASS. These are historical assertions to reproduce, not labels to rewrite based on a new diagnostic. A correction of interpretation can say “lower plateau firing under noisy step input” until preserved step sensitivity is separately supported. The manuscript also already identifies the same-seed pairing issue, so paired statistics are a correction anticipated by its own limitations. [Task B claims](https://github.com/20171806011/Temporal-Attention-Neuron/blob/85213f0d417d54e4f48b301ed1c0e4200ef3c421/snapshot/manuscript/sections/experiments.tex#L111-L156); [paired-statistics caveat](https://github.com/20171806011/Temporal-Attention-Neuron/blob/85213f0d417d54e4f48b301ed1c0e4200ef3c421/snapshot/manuscript/sections/conclusion.tex#L15).

The separate information analysis uses 3000 samples of a multifrequency sinusoid, seed 1, and TAN window 5/leak .5/threshold .5, with a rectified surprise implementation. It is not a validation of the native Task B operating point or its endpoint. Its manuscript separately discusses both noise information and clean change-rate information. Merely reducing `I(noise; output)` has the same silent-output degeneracy: a constant output has zero information about both noise and clean signal. Joint preservation and cost accounting are required. This review does not validate its estimators or reproduce its MI results; that remains a separate bounded audit, not part of the current step-preservation experiment. [MI signal construction and parameters](https://github.com/20171806011/Temporal-Attention-Neuron/blob/85213f0d417d54e4f48b301ed1c0e4200ef3c421/snapshot/code/experiments/information_analysis.py#L571-L587); [manuscript information claims](https://github.com/20171806011/Temporal-Attention-Neuron/blob/85213f0d417d54e4f48b301ed1c0e4200ef3c421/snapshot/manuscript/sections/analysis.tex#L71-L110).

The prospective test concerns preservation of one known step under the original noise process. It cannot establish general denoising, biological implementation, superiority of attention itself, or invalidate the separate positive P1A evidence.
