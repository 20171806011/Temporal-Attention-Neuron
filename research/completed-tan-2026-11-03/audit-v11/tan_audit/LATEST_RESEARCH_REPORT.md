# Latest TAN research outcome: constructive N=2 binding

The new constructive control answers a different and useful question from the preceding same-state counterexamples: **are separate per-key records at query time inherently required?** For the ideal N=2 task, they are not. A declared nonlinear online writer can store the first(k,v) pair and transform two payload registers into a line's slope/intercept when the second event arrives. The query decoder then receives only(a,b,q).

On512 fresh original-generator histories, clean binary64 recovery succeeds for both targets with Ecomp5.08e−16; M0 is exact. All18 constructed support checks and clean query/value swaps pass. This is standard affine interpolation, not new mathematics; the inspected repository did not already implement it as an online carrier. It changes the encoder, input ports, controller and readout, so it does not demonstrate original TAN or a biophysical neuron.

The complete honest budget is two persistent real payload registers **plus** a2-bit phase/error controller, separate raw key/value ports, event-onset/reset/clock control, division and other write arithmetic, combinational temporaries, atomic overwrite and ideal analog multiplication/addition at query. It does not retain a hidden key cache after the second event. Native TAN's summed input/novelty interface is insufficient to provide separate low-key k/v inputs for free.

The actual generator's spacing yields tight closure bounds |a|<=120,|b|<=297. Bounded coefficient/query errors obey

`|e| <= 2.5*eps_a + eps_b + (120+eps_a)*eps_q`.

Under the fixed .001 fractional-fullscale perturbation, IID Ecomp is.19257, compared with M0's.001986 under its own explicitly different coordinate scales; this is not equal biological noise energy. Uniform10ms postencoding leak gives.12890, differential leak.30232, and leakage before the second write1.69115. A preregistered valid-key history makes the leaking first key collide exactly with the second, producing a singular write. These distinguish clean representational sufficiency from retention and robustness.

Precision and range guards must remain separate: IID binary32 error is small(max3.96e−6). Sixteen adversarial binary32 cases trigger the chosen tight coefficient-range guard although their raw answers remain correct for those symmetric/correlated-casting fixtures. Their fallback failure is a device-range policy consequence, not an inherent inability of two coefficients to represent the response. All raw and guarded predictions are retained.

This finding complements rather than invalidates the prior results: the tested modified TAN recurrence has binding ambiguities; its known-key inverse uses privileged side information; a **different explicit online write law** can retain the N=2 query function without storing every key separately. No N=3, minimal state-count theorem, native spike readout, biological equivalence or unconditional noise robustness follows. All original P1B labels and historical outputs remain unchanged.
