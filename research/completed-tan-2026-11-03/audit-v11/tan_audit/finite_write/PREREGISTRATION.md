# Finite-time division-free anchored residual write

Frozen 2026-11-02 before fresh input generation or candidate outcomes. One candidate, two analytically fixed resource budgets; no architecture, gain, duration or step-size sweep. This tests finite-error behavior directly and does not invoke the previous exact-overwrite obstruction as a finite-error impossibility theorem.

## Candidate and feasibility contract

The candidate is enriched relative to registered TAN. Payload states K,V,S retain the first anchor and a learned slope. Initial states are zero. Two stage bits distinguish first-event pending/capture, second-event pending/write, ready and error, using externally supplied event-active/onset/offset/reset/read-clock signals. No position list or second-record cache is accessible to the writer or decoder.

First active event: integrate 100 literal Euler updates of K <- K+.01*(G*k-K), V <- V+.01*(G*v-V), with fixed G=1/(1-.99^100). S stays zero. This is finite leaky charging with tau10 ms and a known-duration calibration gain. There is no assignment K=k or V=v at offset. G is a shared offline constant, not data-dependent inversion. After capture, gated derivatives hold K,V fixed; S is held except during the second event. Perfect holding is an enriched resource, not native decay.

Second active event: for the entire original 10 ms event, update S <- S+h*gamma*d*(v-V-d*S), d=k-K. Recompute the residual from payload and current input at every update. No slope/intercept division, convergence shortcut, exponential propagator, algebraic endpoint overwrite or hidden exact history is permitted. Query receives only K,V,S, current q and shared constants, returning V+S*(q-K). This enriched multiplication/readout is not native TAN's analog or spike decoder and has no simulated hardware latency.

Raw k,v are separate binary64 current input ports, unlike native k+v/novelty. Three explicit binary64 scratch registers implement a sequential subtraction/product schedule and are zeroed between updates; count all three as allocated computational storage, additional to the three payload states. Two input ports and output precision are external assumptions. The implementation thus has three retained payload reals plus three temporary reals (192+192 bits at simulator width), two stage bits and event/control signals. It is not a three-state physical TAN implementation. Arithmetic uses products/subtractions/shared constant multiplication; runtime data-dependent divisions are zero. Ideal analog arithmetic/precision, input drive, switched hold and reset need physical circuitry that this model does not supply.

Fixed state guard ranges: K in [0,2.5], V in [-3,3], S in [-128,128]. No clipping. Excursions <=1e-12 outside K/V bounds are counted as floating roundoff; larger excursions invalidate the row with fixed zero prediction and remain in every denominator. Payload initial zero is included in extrema. The theory establishes sufficient nominal range bounds. No input, process, sensor, gain or timing noise is added. Exactly 100 first-capture steps and perfect hold are explicit feasibility assumptions; analytic timing sensitivity will be reported separately, without adding empirical arms.
