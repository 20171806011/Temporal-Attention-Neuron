# DEND-POP-1：保留原生发放的多神经元树突计算

这一阶段将研究对象转向多个神经元的局部树突计算，不预设单个 TAN 神经元全面优越。已完成一个小型、可证伪的固定连接原型及状态数匹配对照。模型保留自身阈值触发与复位，没有额外输出脉冲发生器。旧实现和既有论文未改动。

**结果：当前树突原型没有胜过普通脉冲网络。** 每个条件有 600 个配对测试样本，未形成唯一输出也计为错误。

| 条件 | 树突原型 | 普通脉冲网络 |
|---|---:|---:|
| 同步、无噪声 | 100.00% | 100.00% |
| 主要干扰条件 | 97.33% | 100.00% |
| 较强干扰条件 | 76.17% | 93.83% |

两者都使用 12 个连续状态；树突原型为 6 个细胞，普通网络为 12 个细胞。这不表示生物能耗或运算量相同。所有连接由任务定义预设，本轮没有学习或参数搜索；输出层是延迟一拍的原生脉冲中继，尚未实现复杂群体协作。

## 复现

从本目录执行，需要 Python 与 NumPy；作图另外需要 Matplotlib。确切运行版本记录于 `results/results.json`。

```bash
python3 test_model.py
python3 verify.py
# 如需重新生成，使用一个尚不存在的输出目录，避免覆盖已存证结果：
python3 run.py --out /tmp/dend-pop-new-run
python3 verify.py --results /tmp/dend-pop-new-run
```

保存的 NPZ 包含输入和完整状态、候选值、脉冲、成本轨迹；不是只有截图或摘要。`MANIFEST.json` 对本目录交付文件提供 SHA-256（不包含它自身和 Python 缓存）。整个实验仅运行一次，CPU 约 1.38 秒。首次检查器因反复解压而停止，修正读取方式后通过，记录见 [VERIFICATION_ATTEMPTS.json](VERIFICATION_ATTEMPTS.json)。
