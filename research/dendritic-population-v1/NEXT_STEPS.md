# Prospective next phase — not executed

The present experiment is complete. Its test set is now observed and must not be reused to select a better dendritic model and then advertised as a fresh held-out test.

1. Locate the requested extra pulse-generation module in any implementation outside the audited sources. Preserve a copy and a native-firing regression fixture before a targeted removal. Do not substitute deletion of soma firing, stimulus generation or count/latency readouts.
2. Specify a population computation that requires interaction, rather than the present one-to-one output relay. A candidate is association of spatial bindings across a delay with distractors, with train/validation/test binding assignments separated before training. Labels may reach an explicit training objective, never the inference input pathway. Retain native somatic firing.
3. Before execution, freeze matched dendritic and ordinary spiking circuits with the same observed inputs, delay access, precision, readout, training examples, update count and parameter-search budget. Report both state-matched and cell-matched comparisons where feasible. Add nonlinear branch versus pooled controls and explicitly compare threshold/gain choices under the same validation budget.
4. Choose and disclose a learning rule. Gradient-based surrogate training, local plasticity and biological learning are different claims. First establish whether a bounded supervised implementation can learn the task; a local-plasticity mechanism would require its own falsifiable comparison. Do not describe either as demonstrated cortical learning.
5. Predeclare one primary held-out metric with abstentions and a paired uncertainty method, and operational resource metrics including events, state bytes and measured runtime. Specify multiple initialization/data seeds, stop conditions, compute cap and a negative-result reporting rule. Fresh test data must remain unopened until model selection is complete.

These are proposed experimental decisions, not completed learning, recurrence, memory or biological validation. The present negative comparison is retained unchanged and provides the starting point for the next protocol.
