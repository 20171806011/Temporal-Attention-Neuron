## Native dynamics, data and learning held fixed

Copy V5 `model.py` and delayed-XOR `data.py` byte-for-byte. Both arms retain 176 float64 parameters, 20 continuous states, six stored previous hidden spikes and two output-count accumulators. DEND has 12 graded dendritic compartments, six hidden somata and two outputs. POINT has 12 native-spiking branch cells, six hidden somata and two outputs. Strict `candidate > .5` firing and reset apply at hidden/output and POINT branch cells. No forward label argument, analog decoder or label-conditioned signal. Surrogate slope `1/(1+5*abs(candidate-.5))^2` with reset derivatives is a learning proxy, not the exact derivative of the discontinuous spike-count objective.

Each 24-step input has six channels. First-bit cue starts at step 2, 3 or 4 for four steps; second-bit cue starts at 10, 11 or 12 for four steps. Amplitudes are uniform [.8,1.2]. A distractor occupies channel5 at7–9, common readout cue channel4 at16–23, and Gaussian .03 noise is added and clipped below zero. Each set balances all four bit pairs; target is XOR. Informative cues end by15, before output counting at16–23. Unique largest output count predicts a class; equal counts, including all silence, abstain and count as incorrect.

Twenty pairs use the literal registry in `SEEDS.json`: train `2060000000+10*s`, test `2060010000+10*s`, initial `2060020000+s`, s=0..19. These namespaces are disjoint from earlier phases. Every pair shares the exact train/test inputs and initial parameter vector across both arms and both recipes. Episodes start from zero state and do not share state or statistics. Check split disjointness and exact independent data regeneration; input uniqueness alone is not proof of statistical independence.

Four cells: DEND/POINT × RATE/.01 and CE/.03, 20 each = 80 trajectories. Every trajectory uses128 training episodes,200 full-batch Adam updates, beta1=.9 beta2=.999 epsilon1e-8, global norm clipping1 and parameter bounds[-2,2]. CE uses .5*counts logits; RATE compares count/8 with target .75/.125. Both add .0001 mean squared parameters. Final checkpoint only. No validation selection, early stopping, seed replacement or test-based repair. Test512 fresh balanced episodes per pair, generated only after all weights have been committed. All80 final models are tested once, including failed training runs.

Changing recipe changes BOTH loss and learning rate. Comparisons may describe this bundled intervention under pairing, but cannot attribute outcomes to CE alone, LR alone, or a biological/representational mechanism. Matrix-work, data, update and parameter budgets match; scalar nonlinearities, resets, activation patterns, cell counts, wall time and energy do not.

## Logged diagnostics and outcomes

Save every initial/final weight and every clipped gradient, loss, raw gradient norm and update norm. Save weights after updates0,1,5,10,20,50,100,150,200. Pre-update training count metrics are logged at all200 steps; checkpoint training activity/margins are evaluated at the nine fixed checkpoints. These diagnostics never select a checkpoint or alter training. Full native final-training and test traces (spikes/counts/predictions/states/candidates) are retained.

For each model report unconditional accuracy, coverage, abstention count/rate, class0/class1 recall with abstentions wrong, 2×3 confusion (prediction0/1/abstain), and output-count margin `count[true]-count[other]` including its integer histogram over−8..8. Ties include silent and nonsilent ties. Episode silence means both readout counts are0; both-saturated means both counts are8. Hidden/output and POINT branch event rates and readout candidate-minus-.5 distributions describe activity, not energy. A candidate margin quantile is descriptive and is not a decision rule.

Run failure: accuracy<.90 OR coverage<.90. A fully silent run has episode-silence fraction1; a fully abstaining run has coverage0. These are distinct from a high but incomplete silent-episode fraction. Classify final train/test transitions: train-fail/test-fail, train-fail/test-pass, train-pass/test-fail, train-pass/test-pass. Report all four cells and every seed. Do not drop silent or failed trajectories.

PRIMARY descriptive contrast: paired DEND CE/.03 minus RATE/.01 unconditional held-out accuracy. Principal unit is20 independently trained seed/data pairs, not10,240 episodes. Use20,000 percentile bootstrap samples of the20 paired indices, RNG2060030001, with95% interval. A practically relevant accuracy difference is5 percentage points, specified for planning, not a claim of adequate power.

SECONDARY exploratory contrasts: POINT CE-minus-RATE; DEND-minus-POINT at each recipe; interaction `(DEND_CE-DEND_RATE)-(POINT_CE-POINT_RATE)`; corresponding paired run-failure risk differences; and mean test-minus-train accuracy for each cell. Use the same predetermined index draws for all paired contrasts. Marginal failed-run, fully-silent-run and fully-abstaining-run proportions use two-sided95% Wilson intervals (z=1.959963984540054,n=20), so zero observed events does not produce a zero uncertainty interval. Mean episode-level silence/abstention is averaged over model seeds and is distinct from run-level risk. Bootstrap differences may degenerate; a [0,0] interval does not prove equality, zero population failure or noninferiority. No episode-bootstrap pseudo-replication. All intervals are pointwise exploratory, no multiplicity-adjusted confirmatory declarations. Interval crossing zero is uncertainty, not equivalence.
