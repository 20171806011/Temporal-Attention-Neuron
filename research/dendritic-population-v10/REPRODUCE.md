# Reproduce V10A

Use an isolated checkout; all scripts write their output paths. Preserve the original frozen run. CPU-only NumPy is sufficient; matplotlib is used for figures. Set OPENBLAS_NUM_THREADS=1, OMP_NUM_THREADS=1 and MKL_NUM_THREADS=1 for each command. Python and NumPy versions are recorded by runner.py. Never rerun runner.py or evaluate.py in the original results directory.

1. Read PROTOCOL.md, DESIGN_REVIEW.md and SEEDS.json. Run check_contracts.py and check_gradients.py on deterministic fixtures only. No task data is generated by them.
2. Freeze the protocol, seed registry, requirements, all source and static documentation into FREEZE.json, including independent verify.py. Commit those exact files. runner.py checks the current Git commit against every frozen file before generating training data.
3. Run runner.py once. It creates results/ and writes five training datasets,40 complete fits and TRAIN_LOCK.json. Commit all training artifacts before evaluating; do not alter the fixed recipe based on training outcomes.
4. Run evaluate.py once. It checks that TRAIN_LOCK.json and every locked file are committed, refuses an existing TEST_STARTED.json, creates five held-out datasets and tests all40 fits.
5. Run audit_gradients.py and the separately authored verify.py. These reuse saved data for verification and must not select models or update trained weights.
6. Run summarize.py to create the report, per-seed/per-pattern tables, resource accounting and figures. It reads saved results only. Generate MANIFEST.json over all deliverables except itself, then commit outputs. Record the exact protocol and checkpoint commits in REPORT.md; scripts store the commit gates in their logs.

The reader should use verification.json and gradient_audit.json to inspect numerical residuals. They are internal checks, not external independent replication. Comparing a reexecution across numerical libraries may change threshold-adjacent trajectories; preserve original outputs and report any such differences.

Stop after this bounded study. There is no authorization in these scripts for paid compute, a larger sweep, a subsequent research phase, public submission or an automatic push.
