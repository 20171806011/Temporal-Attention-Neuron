# V10 scientific design review before data

The user's return to dendritic/population computation is scientifically useful. Three claims in the blueprint require correction before a test can be interpreted.

First, (b0 AND b1) OR (b2 AND b3) is not a single static linear-threshold function. Let u=(1,1,0,0) and v=(0,0,1,1) be positive inputs and r=(1,0,1,0), s=(0,1,0,1) be negative inputs. Since u+v=r+s, a classifier requiring w·u>t and w·v>t while w·r<=t and w·s<=t would require the same sum both >2t and <=2t, a contradiction. This proof applies only to one memoryless affine threshold on these four bits. It is not a lower bound for a recurrent network, a finite-window spiking cell, a network with branch cells, or the implemented POINT baseline.

An ordinary two-subunit threshold network can implement the function exactly: z1=1[b0+b1>1.5], z2=1[b2+b3>1.5], y=1[z1+z2>.5]. A corresponding graded construction uses ReLU(b0+b1-1) and ReLU(b2+b3-1), followed by the same final threshold on Boolean inputs. These are abstract truth-table constructions, not claimed trained solutions of the present temporal/reset model or its two-output count decoder. They show that local nonlinear decomposition is available to ordinary point units too. The strong POINT baseline already has2h native spiking branch cells; replacing it by a lone affine unit would manufacture a comparator mismatch.

Second, V1 already found that handwired branch-local nonlinear computation can preserve pairing information lost by pooling: its DEND and POINT_NETWORK both solved the clean task, while POINT_NETWORK was more robust in the saved jitter/noise conditions. V10 therefore tests learned input allocation and size scaling under the retained native equations, rather than claiming discovery of the V1 effect. With dense learnable access and no new pooling intervention, V10 cannot by itself identify the necessity of partitioned nonlinearities. It compares two implementations with different local nonlinear/reset operations and matched parameters/state at each h.

Third, four continuous currents do not define Boolean conjunction without a coding rule. The frozen task explicitly draws low/high amplitudes from latent bits and samples all16 patterns equally. All-four-high and all three-high patterns are positive; cross-pair-only patterns are negative. It reports both class recalls because pattern balancing gives7 positive and9 negative patterns. The held-out distribution contains new noisy amplitude realizations of known patterns; it is not compositional extrapolation to unseen patterns.

Poirazi, Brannon and Mel used a detailed CA1 compartment model to motivate a two-layer abstraction of average firing rate, with sigmoidal dendritic subunits and somatic pooling/thresholding. This is a model-based abstraction under specified stimulation and rate coding, not a universal theorem that dendrites dominate all point networks. [Poirazi et al., Neuron37:989–999,2003](https://pubmed.ncbi.nlm.nih.gov/12670427/), DOI10.1016/S0896-6273(03)00149-1.

Polsky, Mel and Schiller used slice experiments, confocal imaging and dual-site stimulation to find sigmoid-like summation for nearby inputs on the same thin branch, while inputs on different branches or widely separated positions on one branch summed approximately linearly in the tested conditions. This supports compartment-specific nonlinear integration; it does not justify saying every same-branch input pair always multiplies or every cross-branch interaction is universally linear. [Polsky et al., Nature Neuroscience7:621–627,2004](https://pubmed.ncbi.nlm.nih.gov/15156147/), DOI10.1038/nn1253.

Schiller and colleagues reported local spikes from coactivated clustered basal inputs, with NMDA receptors carrying most of the charge. Our discrete ReLU branch states do not model those conductances, ionic fluxes or their energy costs. [Schiller et al., Nature404:285–289,2000](https://www.nature.com/articles/35005094), DOI10.1038/35005094.

The proposed two-timescale task is deferred. Both V2–V8 architectures have the same .85 branch and .65 soma/output retention factors and can store subthreshold analog states without firing each step. No milliseconds-per-step mapping has been established here. The [native-eight-stage timescale report](../completed-tan-2026-11-03/native-eight-stage/timescale-heldout/REPORT.md) used a modified known-key model, altered coupling/inputs, two analog samples and a bounded equation-based inverse, rather than the population hard-spike count decoder. Its tau_A150ms/tau_m10ms comparison cannot be transferred to V10 as an established mechanism. Increasing its time constant also changed finite-window charging, not only retention. That report already labels its costs model-unit proxies, not ATP or measured physical energy. Graded state is not demonstrated to be free, and lower external spike count alone does not establish energy efficiency.

Primary-source abstracts and the saved repository reports were inspected before this design. Publisher full-text retrieval was unavailable for one article; no claim of a full-text reanalysis is made. No experiments were run as part of this review.
