# 槽位逐出后的预热态替换

双槽读取沿用封存 LEARN 和 ORACLE 权重。逐出门方案在可见读门上升沿检查既往逐出与余弦阈值 `1/√2`。满足时替换分支、胞体、输出膜和上一隐层脉冲。固定预热态是相同权重在 25 步全零外部输入后的原生状态。自然态诊断使用同一基础例删早期轨迹在读门前的原生状态。

## 共同主终点

12 个训练区组，每区组 512 个新样本。区组 bootstrap 重采样 50,000 次。两项各用 97.5% 百分位区间，Bonferroni 名义家族覆盖率为 95%。
