# 探索性时间选择：DEND＋TAN 分支注意力

2026-11-08。本轮完成24次拟合、9600次更新、144项评估，完整保留四模型、两固定学习率和三个新训练种子。本轮是预先冻结的探索任务；结果用于形成假设，不与同一批数据构成独立确认。

任务要求结合先前标记与两个相反内容事件的先后顺序，输出被标记事件的内容。标签由事件内容决定，不使用注意力公式。因两个候选彼此相反，它也可由时间异或、记住首个内容后按标记反转或选择性编码解决，不能称为一般内容检索。

| 事件 | nominal时间（零基索引） | 内容与作用 |
|---|---|---|
| 相关性标记 | t8或t12，二选一 | 通道2标记两步后的候选；自身不携带类别 |
| 第一候选 | t10 | 通道0或1表示首个内容 |
| 第二候选 | t14 | 内容与第一候选相反；两候选实际幅值相同 |
| 无关干扰 | t9、t13、t15 | 通道3，与标记和候选均不重合 |
| 统一查询 | t16至t23 | 通道4恒为1，以两个原生输出计数决定类别 |

cue_gap3只把标记提前到t7或t11，候选、干扰和查询不移动；其他条件及严格匹配规则见下文。

## 两个预定主比较

主终点为每个固定学习率下nominal条件的FULL−NOATT平衡准确率（BA）配对差。两模型具有相同五步历史、surprise、tanh门和分支接口，仅上下文权重不同；各自从头训练，因此差值包含训练适应。

| 学习率 | 三个种子差值（百分点） | 平均差 | 逐项95% bootstrap区间 |
|---|---|---:|---|
| 0.01 | 0.00 / 0.00 / -75.00 | -25.00 | [-75.00, 0.00] |
| 0.0025 | -1.56 / -0.39 / -12.50 | -4.82 | [-12.50, -0.39] |

仅三个独立训练块。区间为20,000次整块bootstrap的逐项未调整95%区间，不用256个测试例或64个四联组代替训练重复。34项其他模型间对比、24项架构内条件差均列入 RESULTS.json，全部是次要探索；没有把其中较有利的条件改称主结果。

## 信息消除与泄漏检查

tag_removed删除标记，同一内容顺序下不同选择的两例输入完全相同、标签相反；query_only删除全部查询前输入，所有输入相同且标签平衡。确定性模型必须给相同输入相同计数，因此这两项严格满足BA=0.5×覆盖率。有平局时BA可以低于50%；这不是额外的记忆能力考核。

四联组内两个候选真实幅值相同，且标记幅值、背景、干扰及查询共享；标签恰好两例每类。候选时间t10/t14固定，标记t8/t12选择两步后的事件。clean仅清干扰通道；strong仅将其加倍；cue_gap3把标记移到t7/t11，候选和查询不变。干扰位于t9/t13/t15，与两套标记位置均不重合。时序改变也可能检验固定时间依赖，不等于单纯延长记忆。

新测试改变幅值、背景与干扰，不增加训练未见的四种逻辑组合。固定事件时刻、二元相反内容和可利用的时间异或策略限制推广范围。FULL优势若出现，也不能直接说明学会一般时间检索；若没有优势、共同失败或触顶，仍保留固定任务而不寻优重跑。

原始TAN模块是固定surprise驱动的标量历史加权：Q=2S、K=H、V=H，不是通用可学习Q/K/V选择器。模型、原始模块及分支接口与上一批逐字节相同；DEND的连续树突、.95/.85保持、原生脉冲/复位和计数读出不改。FULL−DEND混入新增历史与注入；GAIN2仅控制线性驱动加倍，不匹配逐样本注意力注入。FULL−NOATT才是共享接口下的非均匀上下文权重比较。

## 完整性与验证范围

源模块/基准等价预检通过 2,988 项，最大前向误差 2.22e-15，代理导数误差 2.35e-10。独立任务夹具 DATA_CHECK 状态 PASS，任务形状代理有限差分最大误差 2.8e-10；这些都不使用科学种子。

独立审计通过 130,225 项，耗时 14.63 秒，最大数值误差 3.55e-15。覆盖 9600 次Adam更新与存储目标值、144 项评价、首末训练前向；12 个最终混合模型使用实际原始标量注入核验，36 个DEND条件与旧实现核对，48 项信息消除条件验证配对计数和数学上限。

科学梯度没有逐步独立重求，梯度契约依靠隔离夹具和锚定代理有限差分检查；硬阈值前向不变，也不声称获得其真实导数。这是本机独立方程核验，不是外部复现。全部训练权重锁定后才生成测试；源与数据完整性见 SOURCE_LOCK.json、FREEZE.json、train/TRAIN_LOCK.json、AUDIT.json。
