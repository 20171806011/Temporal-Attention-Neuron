# 固定时间选择任务的训练目标对照

本批为前一批之后独立冻结的探索实验。目的：检验改变训练目标能否减少共同静默/饱和，增加正确决策及决策覆盖率，并改善跨种子可靠性。不预设FULL注意力胜出，不更改任务追求注意力优势。

## 三个预定损失及归一化

设c=(c0,c1)，s=c0+c1，d=c正确−c错误。所有mean仅对样本求均值。

- CE = mean(log(1+exp(−.5d)))，与旧版softmax(.5c)完全一致。
- COMMON = mean((s−8)^2/32)。
- COUNT = mean(((c正确−6)^2+(c错误−2)^2)/16) = COMMON + mean((d−4)^2/32)。
- CECOM = CE + COMMON；共同项系数固定为1。

三目标分别CE、COUNT、CECOM，另各自加.0001 mean(w²) L2。COMMON每路计数导数为(s−8)/(16N)。COUNT类别差异项导数为±(d−4)/(16N)。在任意平局上，COUNT和CECOM的计数梯度相同；去掉共同项后两种类别项的梯度也相同（正确路−.25/N，错误路+.25/N）。非平局时不要求相同：COUNT偏好(6,2)，CECOM在可行计数范围偏好(8,0)。不同损失不按测试表现调尺度，不声称同一学习率意味着相同实际更新大小。

COUNT同时改变共同模式约束、差异项形状和目标间隔，所以COUNT改善不能单独归因共同模式。CECOM相对CE是更局部的共同项增补，但总梯度裁剪、Adam和状态反馈仍会耦合两部分。它检验加入该项的干预效果，不证明共同模式未约束是唯一失败原因；改善也不等于发现注意力优势。

## 因子、种子、优化、停止规则

3全新配对训练块×4架构×3目标=36次训练。每块共享同一初始化和训练/测试数据，所有模型无条件完成全部对照；不筛选旧模型，不补种子，不以成绩决定扩大。单学习率.0025固定选择于本批科学数据前，以容纳至少三块和三个目标，不比较两档学习率、不得泛化为最优学习率。

训练seed3991010000+100s，测试3991020000+100s，初始化3991030000+s，s=0,1,2。训练400全批更新，无早停/择优检查点。Adam(.9,.999),eps1e-8；L2加完后整体L2范数裁剪到1，权重[-2,2]；固定代理spike梯度和整个时间历史反传。全部最终权重TRAIN_LOCK后才生成测试数据。216最终评价（36×6）。训练过程计数不作为选择依据。

每步保存裁剪后梯度、计数、loss/总norm/任务norm/L2norm，以及差异loss、共同loss、L2loss、总loss、两个计数梯度norm和总计数梯度norm。k=0,20,...380,399保存原始参数梯度向量的差异/共同/L2三部分；共同项额外反传，不额外前向。CE无该额外反传，COUNT/CECOM各21次。这些参数梯度可重构裁剪前总梯度，但不等于Adam各项贡献。诊断成本计入账本。

一次科学运行总墙钟上限840秒，独立审计另300秒，单工作进程，线程数1，内存1GiB、新产物1.5GiB上限；异常/超时保存部分记录且停止，不续训。禁止安装、付费云/GPU、推送或修改旧封存目录。fixture计时先行：144更新（各架构×目标12步）、独立种子79996001/2；预估=2×1.1×400×3×12单元后6步时间中位数之和+100秒。若预估≥840则停止可行性阶段，不自行缩小后续科学结果。fixture不使用科学种子，不按性能选因子。

## 终点、统计与可靠性

八个预定主比较：nominal上各架构COUNT−CE和CECOM−CE的配对BA差；同时逐项报告决策覆盖率、正确决策比例（本平衡数据与BA相同）、静默[0,0]、饱和[8,8]、其余非零平局、预测类别分布、所有种子原值。跨种子报告范围/标准差、BA≥.75/.90且coverage≥.90的种子数（描述性，无准入门槛），不以单个较好种子代表整组。n=3不足以精确可靠性/普遍机制结论。

其他五条件及FULL−NOATT各目标、COUNT−CECOM名义条件作为探索性次比较完整保留。whole-block配对bootstrap20000次，seed3991900001；点态未做多重比较校正的95%区间，仅描述不称确认性显著证据。不得将条件改善自动解释成抗干扰/注意力优势；可能来自退出平局状态。

核验：固定源码和数据哈希；独立数据再生、全部原生测试计数/状态、首末训练前向、所有Adam更新；独立计数损失导数与代理扩展有限差分；目标/辅助项梯度分解重构；数学缺信息负对照；实际源TAN标量注入。代理有限差分不等于硬阈值函数真实导数，科学全程梯度不逐步独立重写验证。

成本报告原生事件、分级传输、递归/输出fanout、稠密前后向MAC、额外诊断反传、注意力操作与60个新增历史槽，绝不据此推断功率/能耗优势。所有失败保留。若新目标仍失败或共同平局不再主导，基于结果另定后续问题，绝不在本批补救调参。
