# 原生读出差距的三个环节

本轮全部 36 个冻结模型和 1,026 个移植条件已完成，神经参数更新为零。在 t15 做反标签完整状态移植时，67.66% 的受体改变了真实查询脉冲栅格，50.84% 改变了两路计数，26.91% 改变了原生平局判 0 的类别。三个训练块均呈现这一递减关系，逐块分别为 56.02% / 34.86% / 14.45%、71.06% / 58.56% / 29.49%、75.91% / 59.08% / 36.78%。这里等权汇总架构、目标、块与两个反标签方向，三个原训练块才是独立比较单位。

## 可访问状态、逐步脉冲与计数

在反标签完整移植中，69.98% 的受体由锁定的联合探针从受体类别转向供体类别。其中有 14.96 个百分点的全部受体仍发出完全相同的查询脉冲栅格，26.67 个百分点仍有相同计数。DEND 第 1 块 CE 模型给出明确实例。其查询前联合探针 BA 为 69.14%，移植时 45.31% 的受体达到探针转向，全部受体仍输出同一个静默查询栅格。当前输出动力学在这些可分内部状态之间没有产生脉冲差别。

16.83% 的全部受体栅格改变而计数相同。另有 23.93% 的全部受体计数改变而原生强制判类不变。前者直接展示计数求和丢失某些时序变化，后者展示同一固定判类区域可以包含多种计数。它们是相对于同一受体原生轨迹的配对比例。

未干预测试中，严格原生、平局判 0、计数探针、栅格探针平均 BA 依次为 33.37%、57.75%、63.90%、68.58%。栅格探针在 24/36 个模型上高于计数探针，另有 7 个相等、5 个较低。两个探针使用相同校准样本与正则，输入维度分别为 2、16，比较仍受特征维度和标准化影响。

对上一轮关注的 [4,4] 平局做了保存记录的事后核对，包含全部 36 个模型。GAIN2 第 2 块 COUNT 的 256 个未干预测试例中，有 254 个恰为 [4,4]，两类样本数分别为 126 和 128。任何只看这对计数的固定二分类器在此子集都只能给出一个类别，BA 为 50%。同一个在独立校准集锁定的栅格探针在该子集为 78.43%。这个例子定位了计数汇总舍弃的类别时序差别。全部子集和分母保存于 FIXED_COUNT_DIAGNOSIS.json。用 `fixed_count_diagnosis.py` 可复算，读取保存数据和系数即可，无神经重放或重新拟合。此核对未列入主终点。

## 局部移植的因果敏感性

t15 只移植分支 d，按供体类别定向的计数差平均移动 +1.003 脉冲，原生判类对供体的正确率平均增加 11.82 个百分点。只移植胞体与上一脉冲相应为 +0.288 脉冲、+1.49 个百分点，只移植输出电位为 +0.127 脉冲、+1.22 个百分点。隐藏组的移动为 +1.337 脉冲、+14.28 个百分点。H 单独移植只适用于 18 个历史模型，平均改变 12.55% 的栅格，供体判类增益 +0.55 个百分点。26 维联合探针不含 H，因此 H 单独移植对该时点的探针分数没有直接影响。

结果强度随训练目标和块变化。FULL 与 NOATT 的分支移植供体判类增益在 CE 下分别为 +30.34 与 +27.60 个百分点，COUNT 为 −0.52 与 +5.92，CECOM 为 +7.94 与 +5.27。FULL/COUNT 的 t15 联合探针为 92.58%，栅格探针 65.49%，计数探针 55.60%，原生平局判 0 为 52.34%。在其完整反标签移植中，85.55% 的受体探针转向供体，但有 45.96% 的全部受体同时保持计数不变。完整历史权重没有跨目标一致的原生转化优势。

分支移植是在同一时点固定其他起始状态后干预 d，因而可说 d 的改变影响了后续原生输出。不同局部移植改变的状态维数和轨迹一致性不同，混合状态可能偏离训练分布。当前的因果敏感性支持分支通路参与，必要性、重新训练后的可替代性与记忆时长均需另测。

## 对照与解释边界

72 个自身重放和 36 个 t9 前缀对照逐步重现受体查询栅格。216 个完整状态非自身移植精确重现供体后续栅格，t19 拼接保留全部受体前四步查询脉冲。t19 的反标签完整移植中，栅格、计数、判类变化率为 57.30%、36.56%、17.51%。它同时使用较短的后续窗口和受体前缀，时间差不能直接视作状态衰减率。

同标签完整移植也有 73.03% 栅格变化，50.95% 计数变化，22.87% 判类变化。其供体方向的平均变化和增益为零，这是匹配组内同标签置换在完整后缀重现时的恒等式，个体扰动仍很常见。反标签完整移植的供体对齐增益同样由原生分类性能和置换决定。用于辨认路径作用的额外信息来自局部移植、变化层级与匹配对照的联合读数。

原任务 t10 已可由固定标记与互反候选解出。结论限于已训练网络在该任务的状态、脉冲、计数与原生规则。必要延迟存储和一般事件检索仍待另行设计。状态可读性和时间栅格的离线分类成绩也需与原生网络使用分开。
