# TAN 宽度扩展结果｜2026-11-08

本轮在原生本地 CPU 上比较 h=24、48、96 的完整 DEND 与 POINT。每个宽度/架构复用相同两个损失候选和一个完整历史调参块独立选配方，再用五个全新的配对种子训练。旧研究数据与结果没有用作本轮 h24 对照。全部性能失败和静默/平票均保留。

**主要发现：扩大宽度没有带来单调、可靠的改善。** 在各自选定的配方下，DEND 的 D96 clean BA 从 h24 的 99.65% 降到 h48 的 49.34%、h96 的 58.27%；POINT 则从 69.85% 升到 h48 的 87.43%，再降到 h96 的 50%。因此这轮数据支持“尺度与训练配方显著相互作用，需要分开检验”，不支持网络越大越好，也不证明更大网络的容量更差。

POINT 的 h48−h24 D96 配对差为 +17.58 个百分点，逐项 95% bootstrap 区间 [3.42,35.11]；h96−h24 为 −19.85，区间 [−34.61,−5.09]。DEND 的 h48−h24 为 −50.32 [−73.26,−23.90]，h96−h24 为 −41.38 [−49.93,−24.90]。仅五个模型块、单块调参，区间不能升级为普遍结构规律。

**同一个低分可能来自不同问题。** h96 POINT 的 D0/D24 均值分别 99.51%/99.40%，但五个模型在 D96 都把全部 256 例判成 0 类：BA 50%、普通准确率 56.25%、覆盖率 100%，没有输出静默。这是明确的延迟条件退化。h96 DEND 的 D0 已只有 65.21%，包含两个从即时条件开始就全判 1 类的种子；另有种子在 D24 出现 222/256 个平票。不能把这些全部归咎于长保持记忆机制。h48 DEND 的差种子也有大量平票，均未剔除。

**移植也受基准行为限制。** h24 DEND 在 D96 的 d-only 调整后双向效应仍约 99.28 个百分点，vp 约 0.21。h96 POINT 在 D24 的 d-only 约 97.03、vp 约 1.20；到 D96，五个模型原本就全判 0 类，连全状态供体转移的类别效应也为 0。这不能单独证明内部完全没有历史信息：供体原读出本身已失去区分。全状态原生计数仍逐例正确恢复。新宽度的 A/B 或标签可解码性本轮未测试。

**训练配方是尚未消除的混杂。** h24 两架构选 CE，h48 DEND 选 RATE、POINT 选 CE，h96 两者选 RATE。历史 h96 CE 候选不是“差一点”，而是两架构都在验证中全平票、覆盖率 0；RATE 于是赢得有限候选比较，DEND 的选中候选验证均分也仅 52.46%。这说明“胜出配方”不等于充分优化。检查保存的历史训练计数还发现：h96 CE 的 DEND 在完成 2 次更新后的检查点、POINT 在完成 5 次更新后的检查点，已进入全部输出计数为 0 的状态，在所列后续检查点直至完成 199 次更新后仍然如此；h24 CE 则后来恢复学习。这里只是一个历史块的诊断，不能据此确定学习率是原因。

下一项最有信息量的问题是：**保持损失相同，降低优化步长是否能避免宽网络早期读出静默，并恢复任务与长保持表现？** 优先在新种子上固定 CE、交叉 h24/h96 与 .01/.0025 学习率，保留两架构和原生读出，并记录训练中输出候选电位及代理斜率。这样同时去掉本轮跨宽度的损失选择混杂，直接干预一个可能的优化原因；比继续扩大到更大的 h 更能解释当前失败。该后续方案须单独冻结，当前结果不冒充其证据。

**执行偏差明确保留。** 最初两块调参方案在 300 秒上限停止，17 个完整拟合和一个 199 步部分拟合均封存；本轮只复用均衡完整的第一历史块 12 个候选，其余不参与选择但全部独立核验。新训练 30 次完成后，评价在 120 秒上限停止，已产生 759 条原始结果（756 条已汇总、3 条未汇总）。单独冻结的 COMPLETION_PROTOCOL.md 仅新增原计划缺失的 81 个条件，实测 16.06 秒，没有重训、换种子、覆盖或重新产生原条件科学结果；三条丢失资源汇总由独立核验重放补记，原 NPZ 不变。原分阶段预算存在偏差，不能写成原方案顺利完整执行。

新训练＋原评价保守计 121 秒＋补充累计 707.77 秒，仍在 840 秒总体科学预算内；此前中断调参的约 300 秒、计时/fixture、独立核验与开发另列。原评价进程未落盘的 CPU 时间及峰值工作集不作猜测，表中明确缺失。全部 840 条条件最终独立核验通过，覆盖原结果、补充结果与三条统计恢复；来源和快照均可追踪。

科学阶段预算累计计入 707.77 秒（原评价保守记 121 秒，补充为实测）；30 次新训练、6,000 次新更新；历史调参复用第一块的 12 次完整拟合，第二块的不完整结果未参与配方选择。反向矩阵 MAC 共 470,679,552,000；逐元素、优化器、文件与审计不含在 MAC 中。原生/分批实现继承已核验的相同源代码；旧方案 300 秒中断预算、18.14 秒 fixture 检查和 3.74 秒短计时另外保留，不记成本轮科学时间。

独立代码核验 PASS：44,238 项、9,599 次 Adam 更新、全部 840 个最终评价；最大数值残差 1.42e-14，核验墙钟 126.53 秒。重放全部调参验证与最终计数/保存轨迹、配方选择、供体机制和资源；核对每次训练初/末前向，不声称独立重求所有梯度。这是内部数值核验，不是外部重复实验。

**What this does not establish / 尚未建立的结论。** 本轮未验证更大规模对 rd0 的帮助，没有定位吸引子数量、长期抗噪稳定性、特定生物区室作用或能效收益。高于另一架构的均值不证明普遍结构优越，训练失败不证明表示能力不可能，区间跨零不证明等价。未运行“挑中最佳宽度后”的新一轮独立确认。

**Limitations / 限制。** 最终仅五个训练块，调参仅一个已完成历史块和两个损失候选；相同布尔模式的新幅值/噪声不是未见过的逻辑组合。简单训练条件存在天花板，长保持和干扰为分布外条件。固定更新数既不等于固定计算量，也不保证各宽度同等优化；初始化、正则与损失选择随宽度的影响无法完全分离。移植的混合状态可偏离自然轨迹，联合与单部分效应不可解释为可加的信息份额。
