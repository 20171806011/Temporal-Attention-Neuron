# Probe-1 v3 clean：完整可达响应映射

## 0. 结论层级及与旧工作的界线

这是固定提交 `85213f0d417d54e4f48b301ed1c0e4200ef3c421` 的 scalar W5 clean response 分析。
不是 P1-B 的 (u,A,r) novelty-conductance 载体；不借用 P1-B 的信息擦除/码本下界。
此前 Probe1 的交换/共同reset证据（父线程报告）只作为历史记录。本分析给出整个 clean 支持域的显式观测映射，并构造无t5/t9放电的跨类别碰撞。
v11是另一噪声检测合同，不解释本轮clean分类率。没有改变P1A/P1B/v11标签。

分清：完整神经元状态包括 W5 和 h；本任务只允许观察 t9..13 的 pre-reset u 与 spike。
本文rank1结论针对后者，不针对完整窗口状态或神经元一般能力。

## 1. 源码约定与 epsilon 的两个版本

1-based 时间：x5=a, x9=b，其余 x1..14=0。零窗口、h0=0。
类别0: a in [0.55,1.05]；类别1: a in [0.95,1.45]；catch: a=0。
Cue b in [0.55,1.45]，独立于目标类别的混合幅度，原读出不接收b。
当前先入W5；S=max(0,x-mean(H))；q=2S；A=tanh(S) C。
u_t=h_(t-1)/2 + A_t；spike iff u_t>1/2；h_t=0 if spike else u_t。
严格等于1/2时不放电。

历史任务 natural_collision.simulate 使用未平移指数：
 C=sum H exp(qH)/(sum exp(qH)+epsilon), epsilon=10^-9。
原 model/tan.py 使用稳定化：
 C=sum H exp(qH)/(sum exp(qH)+epsilon exp(q max H))。
二者因epsilon而不精确相同。前者是本轮主公式；后者单独认证并实际调用已校验的原类。

## 2. t5到t13的全部分支

设 R(z)=z 当 z<=1/2，否则0。
定义 D(a)=tanh(4a/5) a exp(8a^2/5)/(4+exp(8a^2/5)+epsilon)。
这是历史任务的u5。原类版本将末项epsilon换成epsilon exp(8a^2/5)。

x1..4=0 => h1..4=0。
t5: H=(0,0,0,0,a), S5=4a/5，u5=D(a)，h5=R(D(a))。
t6..8: 当前为0、窗口均值非负 => S=0、A=0。
因此 h6=h5/2，h7=h5/4，h8=h5/8。由于0<=h5<=1/2，不会有额外spike。

t9: H=(a,0,0,0,b)，
 S9=(4b-a)/5 >= 0.15 >0（catch时下界更大），q=2S9。
定义
 C9(a,b)=[a exp(qa)+b exp(qb)]/[3+exp(qa)+exp(qb)+epsilon]，
 T(a,b)=u9=R(D(a))/16 + tanh(S9) C9(a,b)。
原类C9将epsilon换成epsilon exp(q max(a,b))。

t10: a被逐出，H=(0,0,0,b,0)。
t10..13: 每步x=0，窗口包含一个正b和四个0 => S=0、A=0。
若T<=1/2，h9=T，后续u=2^-j T<=1/4，不会再spike。
若T>1/2，h9=0，后续u全部0。

所以任务10维特征严格等于
 F(a,b)=(T, R(T)/2, R(T)/4, R(T)/8, R(T)/16,
          1[T>1/2],0,0,0,0)。

关键：t9放电不会把特征中已经保存的pre-reset u9抹成0。只保留h9或spike将是不同observable。
即使t5放电，a仍在窗口中，直到t9仍能进入C9；t5reset不等于完全删除目标。

D(a)对a>0严格递增。其阈值边界约1.105331432855（历史任务）、1.105331433055（原类），本包有端点区间证书。
跨过该边界，h5从临界值1/2变成0，使T右极限比左极限小1/32；不是连续全局逆。
临界点本身严格遵循不放电规则。t9分支又令F有离散的spike/尾部切换，但T始终是第一个坐标。

## 3. 不是维数猜想：精确rank、等值曲线及真实碰撞

在不穿越t5reset、t9threshold等分支界面的区域，F=G(T)。其Jacobian最多rank1。
下面还证明历史任务在允许支持域 T_b>0，因此其有效rank恰为1，而非仅从输入维数猜测。

将epsilon看作额外固定的零值质量。令p_a=exp(qa)/Z, p_b=exp(qb)/Z，C=E_q[H]，V=Var_q(H)>=0。
 C_b=p_b[1+q(b-C)]+(8/5)V，
 T_b=(4/5)sech^2(S9) C+tanh(S9) C_b。
C>0，S9>0。若a<=b，方括号>=1；若a>b，C<=a，且
 q(a-b)=((8b-2a)/5)(a-b)<=9a^2/40<=0.4730625<1。
所以T_b严格为正。

因此在平滑域内，T=常数给出1维光滑等值曲线 b(a)，斜率为 -T_a/T_b。
这不是对任意非线性神经元的秩推论，而是本响应的显式因子分解和导数性质。
原类稳定化epsilon改变导数细节；本包对其碰撞使用独立的连续性/端点符号证明，不偷用历史版本的单调性定理。

固定参考对 a0=3/4,b0=1，属于label0独占幅度区。T0约0.356598402112（历史任务）。
两个固定的label1幅度为 a1=17/16 和 a2=5/4，均严格大于1.05，不在类0/1重叠区。
分别定义b_j为 T(a_j,b_j)=T0 在[0.9,1]中的根。
精确Fraction指数区间证实两个端点残差异号，介值定理给出精确实数根。
历史任务T_b>0还保证各根唯一。

结果：
 a1=17/16: b1约0.94068377407789693；D(a0)=0.153368..., D(a1)=0.443106...。
  两条历史的t5和t9均不spike，是无reset的跨类别碰撞。
 a2=5/4: b2约0.95088245134434121；D(a2)=0.716678...，t5spike，t9不spike。
原稳定化类也在同一固定括区存在碰撞，根值单独记录。

严格相等指IVT定义的实数根；打印小数或转换float64不是根的精确表示。
数值差为0也不替代数学证明；非零约1e-16残差也不推翻实数碰撞。
这些幅度与cue都在任务支持内部；标签不是根据输出新造的，而由原有幅度支持确定。

由此不存在对所有合法clean输入都正确的分类器，无论decoder是否线性。
但是不能从几个碰撞推出平均正确率至多1/3或其他数值。
若要证明分布级正的不可约风险，可进一步利用这些内部点周围的开集、正类别密度及T_b>0，推出两类在一个非零长度T区间有重叠推前密度；本包未积分其大小、未计算Bayes准确率。

## 4. 并非“a完全不起作用”：b已知时的局部逆

在原历史任务的固定小矩形
 a in [0.749,0.751], b in [0.999,1.001]，
Fraction区间计算认证
 0.1008990201 < T_a < 0.1110094455，
 0.8218583047 < T_b < 0.8508910734。
整个矩形D(a)<1/2；导数公式包含D'(a)/16，并未忽略历史膜电位。

因此给定b时T对a在该区间严格单调；(T,b)对(a,b)的Jacobian行列式为T_a>0，局部可逆。
若两个可能状态都在此矩形，逆误差的一个保守界为
 |delta a| <= (|delta T| + M_b |delta b|)/m_a。
中心点T_a约0.105941、T_b约0.836354，cue的一阶影响大于target。

但精确b是额外的oracle字段/观测资源，不是原10维特征已免费包含的信息。
本轮没有借这个oracle算原任务准确率，也没有声称有全支持域的单值逆。
t5跳变、其他区域的T_a零点/折叠仍可妨碍全局反演；未对它们作穷尽搜索。

## 5. 线性读出的限制与混合训练的另一条因果链

在clean流形上，任意原线性三分类logit可写成
 l_k(T)=alpha_k+beta_k T+gamma_k R(T)+delta_k 1[T>1/2]。
训练集标准化也是仿射变换，不改变这一描述。
也就是每个t9分支上只有关于T的直线族；原10维不等于10个独立target观测。
这并不意味着任何非线性decoder也相同。非线性decoder可以利用T的类别分布形状，但不能区分精确同F点。

mixed-clean/distractor共享读出时，distractor响应不必位于同一clean曲线上。
混合目标可能改变clean上的决策边界；这是尚未被本轮实际干预检验的decoder因素。
clean约33%不能被本映射定理定量归因，也不能被宣称是原输入信息的最佳可达率。

## 6. 有限精度与噪声

本包主执行为原float64，无新增量化/过程噪声。允许域内t10..13只有正常量级的乘1/2，实际固定fixture从float64 u9重建tail逐位一致。
更粗输出量化会扩大观测等价类；有限精度不能被当作隐藏的额外a通道。
对近碰撞若输出扰动集合重叠，稳健解码同样不可能。
多次带独立测量噪声的tail观测可改善T的估计精度，但不会把T一条方程变成独立的a,b方程。
若向动力学新增噪声导致S重新打开，那是改变了任务/模型，不能引用本公式而不重新推导。
