The fixed episode mapping, independent repeated probes, endpoint renaming, and scoped codec-reference statement are accepted. The scope and factorial design do not need another redesign.

### 1. Proposition 6.1 must be restricted to events entering with zero gate

The [proposition](C:/Users/李则徐/Downloads/TAN_Review/P0_20260917_181757/p1_experiments/p1b/P1B_PRE_REGISTRATION_PROTOCOL_V2_2.md:123) currently states that **any** event with \(K_i\le1.4\) produces \(A(t)=0\).

That is false when an earlier event has opened the gate. During a subsequent zero-novelty event,

\[
A(t)=A(t_i)e^{-(t-t_i)/\tau_A}.
\]

If \(A(t_i)>0\), the gate remains positive, and the later event’s value can enter the membrane through \(A(t)(K_i+V_i)\).

The correct statement is:

> Under M1’s initialization and no-bypass input contract, the first active event is erased whenever its key is at or below 1.4. More generally, this applies to an event that begins with \(A(t_i)=0\) and receives zero novelty throughout its presentation.

The \(7/12\) population bound survives this correction because its argument concerns the **first active event**. Its assumptions must retain independent values, uniformly selected distinct requests, and no alternative access to the erased value.

Also, the separated-key generator is reflection-symmetric about 1.4; separation conditioning does not preserve an exactly uniform marginal key density. Symmetry is sufficient for the required probability \(1/2\).

Please call this a **model-specific information-erasure bound**, not an inherent physical limitation of all surprise-gated leaky carriers.

### 2. Both proposed validity floors are below the corresponding registered query-blind nulls

The [null and floor section](C:/Users/李则徐/Downloads/TAN_Review/P0_20260917_181757/p1_experiments/p1b/P1B_PRE_REGISTRATION_PROTOCOL_V2_2.md:145) correctly gives the \(N=2\) delivery null, but still uses the old identity-based null for \(N=3\).

For the same fixed-order, distinct-candidate control used by the [frozen implementation](C:/Users/李则徐/Downloads/TAN_Review/P0_20260917_181757/p1_experiments/models.py:123), under independent uniform values and uniformly requested distinct ordered targets:

| Condition | Query-blind joint **delivery** probability | Proposed floor |
|---|---:|---:|
| \(N=2\) | \(167/288\approx0.57986\) | 0.50 |
| \(N=3\) | \(62/243\approx0.25514\) | 0.25 |

For completeness, the \(N=3\) calculation follows by enumerating the six possible ordered requests. Writing

\[
p=P(|V_1-V_2|<0.5)=\frac{23}{144},
\]

and

\[
r=P(|V_1-V_2|<0.5,\ |V_2-V_3|<0.5)
=\frac{67}{2592},
\]

gives

\[
P_{\mathrm{blind},3}=\frac{1+3p+2r}{6}
=\frac{62}{243}.
\]

These are analytical calculations, not simulations.

**Neither floor establishes performance above this registered null.** G1.3 must also use the appropriate \(N\)-specific null rather than applying \(167/288\) indiscriminately.

There is a separate scope issue: v2.1 required 0.80/0.40; v2.2 lowers those thresholds after the erasure bound was identified, while §6 commits not to lower thresholds to hide the result. A prospective amendment is possible, but it changes the question being validated.

Two defensible choices are:

- Preserve the earlier performance criterion and register the predicted insufficiency of M1.
- Explicitly register a lower-performance mechanistic audit, without describing its floors as superiority to the current query-blind control.

If a different memoryless null is intended, define and derive it separately. Do not substitute one null for another through the phrase “pure chance.”

### 3. The collision fixture uses incorrect weights and compares the wrong value separation

There are two independent problems in the [collision annex](C:/Users/李则徐/Downloads/TAN_Review/P0_20260917_181757/p1_experiments/p1b/P1B_PRE_REGISTRATION_PROTOCOL_V2_2.md:174).

**First, the stated \(c_i\) is not the exact coefficient of the registered Euler recurrence.**

For step size \(h\), no spikes, and the specified old-state update,

\[
u_{n+1}
=\lambda u_n+\frac{h g_A}{\tau_m}A_n(K_i+w_VV_i),
\qquad
\lambda=1-\frac{h}{\tau_m}.
\]

The value coefficient at encoding completion is

\[
c_i=
\frac{h g_Aw_V}{\tau_m}
\sum_{n\in\mathcal E_i}
A_n\lambda^{N_T-1-n},
\]

where \(\mathcal E_i\) contains the integration steps belonging to event \(i\), and \(N_T=T_{\mathrm{enc}}/h\).

An ordinary event-average gate multiplied by one exponential is not this discrete coefficient. It cannot support a machine-precision collision assertion without an additional derivation.

**Second, the relevant separation is between the same requested operand in two histories.**

The fixture changes

\[
V_1=-1.5 \quad\longrightarrow\quad V'_1=-1.0.
\]

Their \(0.50\)-tolerance acceptance intervals overlap. For example, the identical output \(-1.25\) succeeds for both histories.

The fact that \(V_1\) and \(V_2\) differ by 3 **within one history** is irrelevant to this particular collision argument.

Required correction:

- Freeze the event positions and compute coefficients from the actual registered recurrence.
- Construct histories \(H,H'\) with identical full state but
  \[
  |V_j(H)-V_j(H')|>1
  \]
  for the same requested target \(j\).
- Verify legal value bounds and the no-spike assumption over both entire encoding trajectories.
- If retaining a smaller perturbation, label it an exact non-injectivity demonstration only—not a proof of failure at tolerance 0.50.

A candidate construction could use \(\Delta V_1=1.5\), with the compensating second-value perturbation computed from the exact coefficients. It still needs its bounds and subthreshold conditions established before being frozen.
