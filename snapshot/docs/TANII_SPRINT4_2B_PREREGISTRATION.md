## 1. 表示映射(全部预注册、非学习)

- **键嵌入**(d 维矩曲线,严格归一化——4.2-A 5b 结论:等范数 + 对称):
  `φ̂_d(x) = p_d(x)/‖p_d(x)‖`,`p_d(x) = (x, x², …, x^d)`;
  `φ̂_d(0) := 0`(pad 槽,能量基准 e^0=1,与标量 TAN 的 pad 行为一致)。
  (归一化改变了表示空间 → 同时报告未归一化对照 `φ_d(x) = p_d(x)`,仅 M2 对照。)
- **查询映射**(d=2 旋转方向 × 惊奇增益,标量查询的最小向量提升):
  `Q_t = c·S_t · û(ω·S_t)`,`û(s) = (cos ωs, sin ωs, 0, …, 0)`;
  `S_t = 0 ⇒ Q_t = 0`(均匀 α,与标量 TAN 的平局退化一致)。
- **ω = 0.4(预注册,功能判据,先于任何运行)**:
  (i) 查询方向必须在遗产查询区间内扫过规范决策边界(见 §3 预测:交叉点 Q\*≈3.706,
  落在 [3.0, 4.0] 内);(ii) Δθ(Q=3→4) = ω·0.8 ≈ 0.32 rad,是"刚刚越过边界"的最小交叉尺度;
  (iii) 该区间内能量保持非负(û 停留在第一象限附近),事件不被 pad 基线淹没、探针不占优
  (无 amplitude-code leakage)。敏感性扫掠 ω ∈ {0.2, 0.4, π/2, π} 全部报告,不改主值。

## 4. 集合协议与基准(冻结)

- 历史集合:每历史两事件 `x_A, x_B iid ~ U(0.3, 2.5)`;位置为 12 个有序对 (p_A,p_B) 中均匀抽一
  (核无位置项,位置不影响事件间 winner——纪律性随机化);pad=0;探针槽=Q。
- **FlipRate_CF = P_H[winner(Q_A) ≠ winner(Q_B)]**,winner = argmax 能量 over {A,B}。
- 基准:确定性中点求积,2001×2001 网格 over [0.3,2.5]²(无 RNG;指示函数积分)。
  模型基准:bench(M0)=0;bench(M1)=1;bench(M2)=bench(M5-E)=**B2 = 0.444527**(已冻结);
  bench(M3;d)=**B3_3 = 0.054937 / B3_4 = 0.028391 / B3_8 = 0.017159**(已冻结);
  bench(M4)=0;bench(M5-I)=**B5I = 0.405772**(ε_I=0.3,已冻结);
  未归一化对照 bench = 0.000000(精确;见 Amendment 2)。
- MC:3 种子 × N_H=10,000;判据 `|p̂ − bench| ≤ 3·SE + 0.002`。
- 未归一化对照(仅 M2):`φ_2(x) = (x, x²)`(不归一化)重复规范反事实与集合,报告对照
  (归一化只重标能量尺度,winner 结构不变——预测:同 P2/P3 且集合率相同,验证)。

## 5. 捷径审计(4.2-A 教训的落实)
