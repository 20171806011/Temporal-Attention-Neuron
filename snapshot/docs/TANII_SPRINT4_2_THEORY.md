## 1. 符号与设定

- 候选键 `K_A, K_B ∈ R^d`,`ΔK := K_A − K_B ≠ 0`。
- 能量 `E_i(Q) = Q^T K_i`(d=1 时退化为标量乘积 `Q K_i`)。
- 硬 winner:`w(Q) = argmax_{i∈{A,B}} Q^T K_i`(平局为零测事件;约定 `w(Q)=A ⟺ Q^TΔK>0`)。
- 查询分布:对 `d ≥ 2`,`Q ~ Unif(S^{d−1})`(各向同性、O(d) 不变概率测度);
  对 `d = 1` 分三种域(见 §2)。
- 软注意力(2 候选):`α_A(Q) = σ(Q^TΔK)`,`σ` 为 logistic;`α_B = 1 − α_A`(见 §6 与 §5)。

## 2. 查询域审计(d=1 的 impossibility 是否成立?——回答 §一 的 4 问)

### 2.1 TAN 的查询到底是什么域?(问题 1)

TAN-I / TAN-II(4.1)的注意力核是:
`E_i(t) = c_a · S_a(t) · x_i`,`S_a(t) = [x_t − μ_t − ε_a]_+ ≥ 0`,
`c_a = β W_q W_k`(β=1, Wq=2, Wk=1 ⇒ `c_a = 2 > 0`)。

因此**有效查询** `γ_t = c_a S_a(t)` 满足 `γ_t ≥ 0`,且当 `S_a(t)>0` 时严格正。
即:TAN 的查询域是**非负标量射线** `D = R_{≥0}`(不是任意实数,不是 ±1)。这是**模型自身推导**出来的约束(relu 惊奇 × 正权重),不是外部假设。

> 结论 1:TAN-compatible query = positive(non-negative)scalar ray。§一问题 1 的答案是"是,严格 Q ≥ 0"。

### 2.2 三域分类(问题 2、3)

| Case | 查询域 | 是否 TAN-compatible | d=1 下能否翻转 winner |
|---|---|---|---|
| A | `Q > 0`(正标量) | **是**(TAN 继承域) | **否**(顺序锁定) |
| B | `Q ∈ R \ {0}`(无约束标量) | 否(需引入负查询通道) | **是**(Q→−Q 翻转) |
| C | `Q ∈ S^0 = {−1, +1}`(归一化标量) | 否(同上) | **是**(±1 给出相反 winner) |

> 结论 2(问题 3):**d=1 的 impossibility 不是 d=1 的固有性质,而是查询域的性质。**
> 只要查询能取两种符号(Case B / C),d=1 就能翻转 winner。

### 2.3 精确的顺序不变性定理(问题 4)

**定理 1(标量顺序不变性的精确条件)**。
设 d=1、`K_A ≠ K_B`、查询域 `D ⊆ R`。则
- 对一切 `Q ∈ D ∩ R_{>0}`:`w(Q) = argmax_i K_i`(胜者 = 键值最大者);
- 对一切 `Q ∈ D ∩ R_{<0}`:`w(Q) = argmin_i K_i`(胜者 = 键值最小者);
- 因此 `w(Q)` 在 `D` 上为常数 ⟺ `D` 不同时包含正、负两个符号类。

证明:`Q K_A > Q K_B ⟺ (Q>0 且 K_A>K_B) 或 (Q<0 且 K_A<K_B)`。∎

**推论 1(TAN 兼容族的顺序不变性)**。TAN 查询域 `D = R_{≥0}` 是单一符号类,故
`w(Q) = argmax_i x_i` 对一切激活查询(Q>0)不变;`FlipRate_CF = 0`。
> **安全且精确的表述**(§一问题 4 的答案):
> "Within the positive-query scalar family inherited from TAN-I (Q ≥ 0), candidate ordering is query-invariant."
> ——不能写成 "one-dimensional dot-product attention cannot route."(后者在 Case B/C 下为假)。

## 3. d=1 带符号标量:已能翻转,但退化(§六 审计)

**定理 2(带符号标量查询)**。d=1,`Q ∈ S^0 = {±1}`:
`w(+1) = argmax_i K_i`,`w(−1) = argmin_i K_i`,二者相反(`K_A ≠ K_B`)。
故 `FlipRate_CF(Q_A=+1, Q_B=−1) = 1`。

**审计要点**:这**不是** TAN 兼容情形(需引入负查询),且是**退化**的:
- 查询空间只有 2 个点(`S^0` 是 0 维流形),`FlipRate_CF ∈ {0,1}`,不能取连续值;
- 胜者由"键值的固定大小次序"决定,符号只是把"自然序"整体取反——它**不能**按内容选择
  "K_A 而非 K_B"当 `K_A < K_B` 时仍选 A(即不能表达 `Q→A` 与 `Q→B` 的任意映射)。

> 结论 3:d=1 带符号是"1 比特、顺序锁定的容量",属于 Level-1 几何容量(见 §8),
> 但不是我们想要的"连续内容条件化排序"。

## 4. d ≥ 2 的几何:解析结果(§五 要求的理论,而非 Monte Carlo)

### 4.1 决策边界与胜者测度

**定理 3(决策边界是大圆,两侧等测度)**。对任意 `d ≥ 1`、`K_A ≠ K_B`,
`B = {Q ∈ S^{d−1} : Q^TΔK = 0}` 是过原点的大(d−2)-球(大超球面),把 `S^{d−1}` 分成
`H_A = {Q: Q^TΔK > 0}`、`H_B = {Q: Q^TΔK < 0}` 两个开半球。

**推论 3.1(等测度)**:在各向同性测度下,`P_Q[w=A] = P_Q[w=B] = 1/2`,
**与 `‖K_A‖, ‖K_B‖` 是否相等无关**(因为边界过原点,决策只看 `Q·ΔK` 的符号)。

证明:`P[Q^TΔK > 0] = P[Q·û > 0]`,`û = ΔK/‖ΔK‖`;`Q·û` 是均匀单位向量在固定轴的投影,
其分布关于 0 对称。∎

> 重要(§五):等范数情形确实有 P(A)=P(B)=1/2——但更强的结论是**任何范数都 1/2**,
> 范数不对称**不**在纯点积硬 argmax 里制造胜者偏置。范数的泄漏只出现在
> (i) ≥3 候选、(ii) 软注意力带温度/偏置、(iii) 学习读出。见 §6。

### 4.2 查询诱发的胜者变异 F_d(§二-B)

**定理 4**。固定 `K`(ΔK≠0),`Q_1, Q_2 iid ~ Unif(S^{d−1})`:
`F_d := P[w(Q_1) ≠ w(Q_2)] = 2 · (1/2)(1/2) = 1/2`,对**所有 d ≥ 2 都等于 1/2**;
对 d=1 带符号(均匀 ±1)也是 1/2;对 d=1 正标量是 0。

> **审计要点**:`F_d` 不随 d 增长(等测度半球下恒 1/2)。因此 `F_d` **不是**能检出
> "d=1→d=2 相变"的统计量。任何想用 `F_d` 论证维度跃迁的方案都必须放弃或重新定义。

### 4.3 反事实翻转率(§二-C、§十)——中心解析结果

**定理 5(反事实翻转 = 查询夹角/π)**。设历史 `H=(K_A,K_B)` 的 `ΔK` 各向同性
(`ΔK ~ Unif(S^{d−1})`,d≥2),固定两个查询 `Q_A, Q_B ∈ S^{d−1}`,夹角
`θ = arccos(Q_A^T Q_B) ∈ [0, π]`。则
`FlipRate_CF := P_H[w(H,Q_A) ≠ w(H,Q_B)] = θ / π`。

证明:旋转到 `Q_A = e_1`, `Q_B = cosθ e_1 + sinθ e_2`。翻转事件
`(Q_A^TΔK)(Q_B^TΔK) < 0` 等价于 `ΔK_1 (cosθ ΔK_1 + sinθ ΔK_2) < 0`。
写 `ΔK_1 = r cosφ, ΔK_2 = r sinφ`,因 (ΔK_1, ΔK_2) 的联合密度在 (1,2) 平面内旋转对称,
`φ` 在 `[0,2π)` 均匀。事件化为 `cosφ · cos(φ−θ) < 0`,即 `φ` 落在两个角宽各为 θ 的区间,
总角测度 `2θ`,故 `FlipRate_CF = 2θ/(2π) = θ/π`。∎

特例:
- `θ = π`(反平行查询):`FlipRate_CF = 1`。
- `θ = π/2`(正交):`= 1/2`。
- `θ → 0`(近平行):`→ 0`。
- d=1 带符号:`θ ∈ {0, π}` ⇒ `FlipRate_CF ∈ {0, 1}`(退化的两个端点)。
- d=1 正标量:无方向自由度 ⇒ `FlipRate_CF = 0`。

> **结论 4(本审计最核心的结构结论)**:
> **反事实翻转能力由两个查询的夹角 θ 控制,而不是由环境维度 d 控制。**
> `FlipRate_CF = θ/π` 对 d≥2 维度无关。d=2 的独特之处在于:
> 查询方向流形 `S^1` **连通**,使 θ 能在 `(0,π)` 连续取值;而 `S^0` 只有 {0,π} 两个退化角。

## 5. 注意力分布与 JSD(§十一 审计——存在一个必须报告的陷阱)

两候选软注意力:`α_A(Q) = σ(Q^TΔK)`,`σ` 为 logistic(`α` 只依赖 ΔK,范数无关)。

- 对**固定历史** H:JSD[α(Q_A), α(Q_B)] > 0 ⟺ `Q_A^TΔK ≠ Q_B^TΔK`。
- winner 翻转 ⟺ `(Q_A^TΔK)(Q_B^TΔK) < 0` ⟹ JSD > 0;但 **JSD > 0 ⟹̸ winner 翻转**。

> **陷阱(必须写进预注册)**:在 d=1 正标量族里,取 `γ_A ≠ γ_B`(两个不同正查询),
> `α_A = σ(γΔx)` 的**锐度随 γ 变化 ⇒ JSD > 0**,但 `sign(Δx)` 不变 ⇒ `FlipRate_CF = 0`。
> 即:**单用 JSD > 0 会在正标量族里误判为"查询条件化再分配"**。
> 因此 §十一 的判据必须取**合取**:"JSD > 0 **且** winner 翻转"才是真正的查询条件化再分配;
> 单独 JSD>0 不足(它只反映锐度/幅度变化,不反映排序变化)。这与你的直觉一致,这里给出精确形式。

## 6. 捷径审计(理论层,§四、§九)——回答"flip 是否只是 shortcut?"

**6.1 范数捷径**:
- 2 候选、纯点积、硬 argmax:决策只依赖 `ΔK`,**范数不对称不产生胜者偏置**(定理 3.1)。
- 2 候选、软注意力:同样 `α_A = σ(Q^TΔK)`,范数无关。
- **但是**:(i) ≥3 候选时大范数键获得更大边距;(ii) 温度/偏置放大范数效应;
  (iii) 学习读出可放大范数泄漏。故**相等范数(或归一化 + 未归一化对照)仍必须**。

**6.2 幅度/位置捷径(与 TAN Probe-2 历史泄漏同类)**:
实际 TAN 窗口有 5 个槽(2 候选 + 2 静默 pad + 探针槽),软注意力分母含 pad 的 `e^0 = 1` 项
与探针槽,`α` **不是**干净的 2 候选 sigmoid。原 Probe-2 的 amplitude-code leakage
(`B>A` 静态幅值捷径、query 幅度压过所有键)正是此类。新 Probe 必须:
- `‖K_A‖ = ‖K_B‖`(或严格归一化并报告未归一化对照);
- 随机化 temporal position / absolute amplitude / candidate ordering / query magnitude / distractor order;
- 探针(query)不得以"内容候选"身份进入候选集(避免"自吸引"与"query 幅度压过键")。

> 结论 5(§九):2 候选点积的纯 argmax 在数学上已无范数捷径,但真实窗口(5 槽 + 软注意力)
> 会重新引入捷径,因此相等范数 + 全随机化 + 归一化/未归一化双报是**必要非充分**控制。

## 7. E-I 拓扑是否改变该边界?(§八、问题 8)

**结论 6:不改变(结构性,非经验)。**
`w(Q)` 是 softmax 能量 `E_i = Q^T K_i` 的 argmax,发生在**任何 E-I 动力学之前**;
E-I 电路只作用于标量聚合量 `C = Σ_i α_i V_i` 与标量惊奇,无法重排候选次序。
因此:
- E-I + 标量注意力:FlipRate = 0(4.1-C/D 已数值确认);
- E-I + 向量注意力:翻转容量仍由核的 θ/π 决定,E-I 只重塑下游响应(增益/脉冲/动态范围)。

> 缺失的组织自由度是**表示层**(查询/键的方向),**不是动力学层**(E-I)。这正是
> 研究链 "Opponent Competition + minimal non-factorizable interaction → ?" 的精确落点:
> 4.1 已把"竞争"排除出路由充分条件,4.2 要测的是**表示交互的最小非因子化**。

**最小非因子化交互(精确对象)**:
- 标量核 `E_i = γ · x_i` 是**可因子化**的 rank-1 形式 `f(Q)·g(K_i)`,故 argmax 与 Q 无关;
- 向量核 `E_i = Q^T K_i` 是**双线性形式**,不能写成 `f(Q)g(K_i)`,查询方向真正参与选择;
- 使方向成为连续自由度的最小维度 = **d=2**(`S^1` 连通;`S^0` 是 2 点)。

## 9. 我们能否合法写 d_min = 2?(§十四、§十五、问题 10)

**不能无条件写 `d_min = 2`。** 理由:
1. 带符号标量(d=1, Case B/C)已能翻转(定理 2)——若把 `d_min` 定义为"最小翻转维度",答案是 **1**。
2. `FlipRate_CF = θ/π` 对 d≥2 维度无关;`F_d = 1/2` 对 d≥2 也维度无关——不存在
   "flip 随 d 单调增长"的相变,真正的间断在**查询域层面**(正射线 = 锁定 vs 对称域 = 自由),
   不在 d=2 vs d=3 之间。

**允许的严格替代表述(必须带限定词)**:
- (a) "Within the positive-query scalar family inherited from TAN, ordering is query-invariant(FlipRate_CF = 0)." — ESTABLISHED。
- (b) "Order invariance is broken exactly when the query is free to cross the decision hyperplane `Q^TΔK = 0`." — ESTABLISHED。
- (c) "d = 2 is the **minimal dimension for a connected, rotationally-symmetric continuous query-direction manifold** (S^1), i.e. the minimal d at which `FlipRate_CF = θ/π` can range continuously over (0,1) rather than being restricted to {0,1}." — 这是"最小整数维几何跃迁"的**唯一**安全表述。

**禁止的表述**:`d_min = 2`(无定语)、"d=2 相变"(无严格序参量/极限定义时)、
"d=2 ⇒ content-addressable routing"(那是 Claim C,默认不成立,见 §10)。

> 结论 8(问题 10):最严格的替代表述是 (c);(a)(b) 是配套的精确边界定理。
> 若坚持用符号,写作 `d* = 2`(带 * 表示"在 TAN 兼容正标量族内,连续查询方向的最小整数维"),
> 并在每次出现处附 (a)(b)(c) 之一。

## 10. 十个问题(理论层)的答案速览

1. **d=1 顺序不变性的精确条件**:查询域 ⊆ `R\{0}` 的单一符号类(定理 1)。
2. **放开 Q>0 后 d=1 是否仍不可能**:**否**。Q 可取两符号即翻转(定理 2)。
3. **d=2 是否产生非平凡 winner 划分**:是。`H_0` 为过原点的直线;`S^1` 被分成两个等测度开半圆弧;边界方向 `Q ∝ ΔK^⊥`(定理 3)。
4. **解析 routing-capacity proof**:有。`P[w=A]=P[w=B]=1/2`(定理 3.1)、`F_d=1/2`(定理 4)、`FlipRate_CF=θ/π`(定理 5)。
5. **Monte Carlo 是否与解析一致**:(待 4.2-A)已给出解析预言:等测度 1/2、`F_d=1/2 ∀d≥2`、`FlipRate_CF=θ/π`、正标量族 0。若偏差 → STOP AND DEBUG。
6. **d=2 是否产生反事实翻转**:是(解析 θ/π>0),但与维度无关、随 θ 连续。
7. **是否只是 shortcut**:2 候选点积 argmax 无范数捷径(定理 3.1);但真实 5 槽窗口 + 软注意力会重新引入,故须相等范数 + 全随机化(§6)。
8. **E-I 是否改变边界**:否(结构性;核在前、E-I 在后)。缺失自由度是表示层。
9. **证的是 capacity/realized/generalized 哪一级**:4.2-A 只能证 **capacity(Level 1)**。
10. **能否写 d_min=2**:不能无条件;只能用 §9 的 (a)(b)(c),核心是 (c)。

## 12. GO / NO-GO 建议与进入 4.2-A 前必须预注册的事项

**审计结论:理论审计通过(带必须采纳的修正),建议 GO(进入 4.2-A 纯几何实验),但前提是:**

1. **定理措辞锁定**(否则审计报告视为未采纳):全部"d=1 不可能"一律改写为
   "within the positive-query scalar family (TAN-inherited)";不使用一般性 "1-D attention cannot route"。
2. **三域分报**:Case A(正标量)/ Case B(无约束标量)/ Case C(±1 归一化)分别报告,互不混写。
3. **统计量替换**:不以 `F_d` 论证维度;以 `FlipRate_CF(θ)`(及对 θ 的解析 θ/π 曲线)为核心;
   把 `F_d = 1/2 ∀d≥2` 作为"维度无关"的**反证性对照**而非跃迁证据。
4. **捷径控制**:等范数 + 归一化/未归一化双报 + 位置/幅度/顺序/query 幅度/distractor 全随机化;
   且探针不进入候选集(防自吸引与 amplitude-code leakage)。
5. **分层声称**:4.2-A 输出只能标 Level-1(capacity);4.2-B(vector-QK TAN)才涉及 Level-2;
   Level-3 留独立 Probe。
6. **Monte Carlo 校验清单**(S4.2-A 必须逐一比对解析值,任一不符即 STOP AND DEBUG):
   - `P[w=A] = 1/2`(任意范数,任意 d≥2;Case B/C 亦 1/2;Case A 为 0/1 退化);
   - `F_d = 1/2`(d≥2 与 d=1 带符号;d=1 正标量 0);
   - `FlipRate_CF = θ/π`(θ 扫 0→π;d=1 带符号只有 {0,1});
   - 正标量族 `FlipRate_CF = 0`(对一切 γ_A,γ_B>0)。
7. **停止规则保留**:若 S4.2-A 数值与上述解析不符 → STOP AND DEBUG,不得进入 4.2-B。
