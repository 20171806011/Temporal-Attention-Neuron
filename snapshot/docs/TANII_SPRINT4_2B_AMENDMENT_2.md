## 2. 运行前解析复核发现:该预测错误

对未归一化键 `p(x) = (x, x²)`:
`û(θ)^T (p(x_A) − p(x_B)) = cosθ (x_A−x_B) + sinθ (x_A²−x_B²)
= (x_A − x_B) · [cosθ + (x_A + x_B) sinθ]`。
在 ω=0.4 的查询区间内(x_A,x_B ∈ [0.3,2.5] ⇒ θ(Q=3) ∈ [0.56, 0.912]、θ(Q=4) ∈ [0.88, 1.232],
均 ⊂ (0, π/2)):cosθ > 0、sinθ > 0 ⇒ 括号恒正 ⇒
`sign = sign(x_A − x_B)` 与查询无关 ⇒ winner = 键值较大者,对两个查询相同。
**正确预期**:未归一化对照 `FlipRate = 0(精确)`,规范 winner(3) = winner(4) = B(无翻转)。

## 4. 机制含义(升级为正面结论,写入结果)

**归一化(等范数条件)不是装饰性控制,而是翻转的机制使能条件**:
原始幅度键把 ΔK 的方向钉在正/负两个象限位置,查询方向(第一象限)只能给"较大键"加分,
标量幅度序保持锁定;只有把键单位化(等范数)后,ΔK 的方向才随候选对自由转动,
查询方向才能越过决策边界。这与 4.2-A 的 5b(等范数≠布置对称,distractor 范数泄漏)
相互印证,并且更强:在 2 候选情形下,**无归一化 ⇒ 容量为 0;归一化 ⇒ 容量 0.4445**。
