## 2. 静态 E-I 对手机制:推导与不等式

不考虑记忆,把 E 单元的"输入→稳态膜电位"映射写为(本 Sprint 的静态约化,即规范 §7 的 R(x),但泄漏归一):

设输入 x 恒定,驱动项为阈值化线性电流:
A_E(x) = [w_E x − θ_E]_+, A_I(x) = [w_I x − θ_I]_+,
E 单元稳态(无脉冲区): h_E\*(x) = [A_E(x) − w_EI A_I(x)] / (1 − λ_E) = g·R_0(x) 形式,
其中 R_0(x) = [w_E x − θ_E]_+ − w_EI·[w_I x − θ_I]_+ 正比于规范 §7 的 R(x)(g ≡ w_EI 对应)。

分段斜率(在 h 无脉冲、x > 0 递增区):

1. x ≤ x_E^on = θ_E/w_E:两者均未激活,h_E\* = 0(静默)。
2. x_E^on < x ≤ x_I^on = θ_I/w_I:仅 E 激活,
   h_E\* = w_E(x − x_E^on)/(1−λ_E),斜率 m_1 = w_E/(1−λ_E) > 0。
3. x > x_I^on:两者激活,
   h_E\* = [w_E x − θ_E − w_EI(w_I x − θ_I)]/(1−λ_E),
   斜率 m_2 = (w_E − w_EI w_I)/(1−λ_E)。

**定理 1(对手非单调性)**:若
(a) θ_E/w_E < θ_I/w_I ≤ x_max(存在中间兴奋窗);
(b) w_EI·w_I > w_E(斜率反转);
则 R_0(因而 h_E\*)在 [0, x_max] 上有一个**严格局部极大值**,位于 x = x_I^on
(左侧导数 m_1>0,右侧导数 m_2<0;分段线性情形为角点极大,连续光滑近似下为真实极大)。
参数 §1.2 满足 (a)(b)(数值:0.8<1.0<3.0;0.8·1.0>0.5)。

**推论 1.1(C1 预注册预测)**:C1 的条件固定点曲线 h_E\*(x\*) 在 x\*≈1.0 处出现严格局部极大,
之后进入抑制下降区。→ P1 预测 PASS(由参数不等式保证,不是数据拟合)。

注意:此非单调性**先于任何 attention 而存在**(C1 无 attention)。因此即使 C4 也出现非单调性,
也不能把非单调性归因于 attention——消融阶梯负责归属。

## 3. 完整 E-I TAN 动力学(规范 §9,逐字实现)

离散时间;每个 tap t 到达输入 x_t。窗口 v_t = (x_{t−W+1},…,x_t)(起始零填充)。
窗口均值 μ_t = mean(v_t)(含当前 tap,TAN-I 遗产)。
分支惊奇: S_a(t) = [x_t − μ_t − ε_a]_+, a ∈ {E, I}。

注意力(仅 C3 的 E 支、C4 的 E/I 支激活;logits 与 TAN-I 核一致——查询为标量):
L_i^a(t) = c_a · S_a(t) · v_{t,i}(i=0..W−1,对窗口内逐槽),
α_i^a = softmax_i(L^a),C_a(t) = Σ_i α_i^a v_{t,i}。
(C2:强制 α_i = 1/W ⇒ C_a ≡ μ_t,无时间组织;仅保留惊奇门。)

每单元激活电流(依模型,见 §4):
A_E(t) = tanh(S_E(t))·C_E(t)(C2–C4;窗口模型)
A_I(t) = tanh(S_I(t))·C_I(t)(C2,C4;C3 时 C_I≡μ)
C1: A_E(t) = [w_E x_t − θ_E]_+,A_I(t) = [w_I x_t − θ_I]_+(无惊奇、无窗口组织)。

膜电位(规范 §9 方程,逐字):
h_E(t) = λ_E h_E(t−1) + A_E(t) − w_EI·A_I(t),
h_I(t) = λ_I h_I(t−1) + w_IE·A_E(t) − w_II·A_I(t)。

Dale 符号结构(突触矩阵,元素非负,w_EE 对 E 自驱取恒等 1,即 E 自身输入电流以单位增益进入本单元):
W_syn = [[1, −w_EI],[w_IE, −w_II]],w_ab ≥ 0。实现中不出现任何"符号违规"抑制参数。

脉冲与复位(规范 §12):
y_a(t) = Θ(h_a(t) − θ_sp),若脉冲则 h_a(t) ← 0。
系统含离散复位,不是光滑连续动力系统;文档与图内均不称其光滑。

### 3.1 条件固定上下文流(规范 §13;正式推导)

把读出时刻的窗口内容冻结为 X\*、探针振幅固定为 x\*(即条件元组 (X\*,x\*)):
则 A_E = A_E(X\*,x\*)、A_I = A_I(X\*,x\*) 均为常数。定义条件驱动
B_E = A_E − w_EI A_I,B_I = w_IE A_E − w_II A_I。
条件递推: h_a(t) = λ_a h_a(t−1) + B_a,a ∈ {E,I},0 ≤ λ_a < 1。

**定理 2(条件固定点)**:在条件递推下(无脉冲区),唯一的条件固定点为
h_E\* = B_E/(1−λ_E),h_I\* = B_I/(1−λ_I),全局渐近稳定(收缩率 λ_a),轨迹
h_a(t) = h_a\* − (h_a\* − h_a(0))·λ_a^t。

**条件零斜线**(Δh_a = 0 的轨迹):h_E = h_E\*(竖直线)、h_I = h_I\*(水平线),
交点 = 条件固定点。

**认识论限制(必须写明)**:该平面只是对**给定 (X\*,x\*) 冻结条件**下的仿射流。
不同 x\* 给出不同平移仿射场;它们不构成单个二维自治非线性系统的内禀相图变形。
不得把条件零斜线的移动表述为"系统相图随输入变形"。图中标题必须含
"Conditional Fixed-Context Phase Plane(固定历史上下文条件相平面)"。
若条件固定点越过脉冲阈值(h_a\* ≥ θ_sp),则真实动力学以脉冲–复位环代替固定点;
该 (X\*,x\*) 标记为"spiking regime",亚阈值分析在该点不适用(审计规则 §7)。

### 4.1 标量查询不变性引理(把 TAN-I 边界平移进 TAN-II)

**引理 3**:对任意分支 a∈{E,I},只要 S_a(t) > 0(标量),logits L_i^a ∝ x_i,
softmax 的 argmax 只由窗口内容 x_i 的大小次序决定,与标量 S_a 无关:
argmax_i L_i^a = argmax_i x_i(S_a > 0);S_a = 0 时 α 均匀(无唯一 argmax,记为平局)。
**推论 3.1(反事实 argmax 翻转率 = 0,预测)**:查询振幅 Q 只会整体缩放 logits(等价于改变温度),
不改变任何槽位排序 ⇒ 对固定历史,FlipRate = 0(C2–C4;规范 §16、§20 判据)。
**推论 3.2**:若未来出现 FlipRate > 0,需要查询通道携带内容或候选键为向量/非平凡结构——
那属于组织自由度的进一步增加(本 Sprint 范围外,记为 UNKNOWN 留待后续)。
C1 与 C2 无注意力候选空间(无 α),P2 判据按预注册标记 N/A(见 §6.2)。

## 5. 主判据 P1:单调性破缺(规范 §15)

对象:E 单元条件固定点曲线 h_E\*(x\*)(主要),以及情节式收敛读数(交叉验证)。
对 57 点网格 x\*_j = 0.2 + j·0.05 计算 h_E\*(x\*_j)(C1–C4),有限差分:

Δ_j = h\*(x\*_{j+1}) − h\*(x\*_j)(j = 0..55)
二阶差分(曲率二次确认): Δ²_j = h\*(x\*_{j+1}) − 2h\*(x\*_j) + h\*(x\*_{j−1})(j = 1..55)

**局部极大候选**:存在 j(2 ≤ j ≤ 54)满足
Δ_j > tol_d ∧ Δ_{j+1} < −tol_d ∧ Δ²_j < −tol_c ∧ 凸起: h\*(x\*_j) − min(h\*(x\*_{j−2}), h\*(x\*_{j+2})) > tol_p。

预注册容差(运行前固定): tol_d = 1e-3(单位:每步 h),tol_c = 2e-3(二阶差分单位 h),
tol_p = 5e-3(凸起单位 h),网格 δ = 0.05。
这些容差高于确定性数值噪声(≈1e-12);小于容差的起伏按"未建立"处理,不称为极值。

**脉冲污染规则**:若候选点 ±2 个网格步内有任何一点处于脉冲区(h\* ≥ θ_sp),
该候选标记为 INCONCLUSIVE(可能只是脉冲边界伪影);P1 判定:
PASS ⇔ 至少一个有效候选;FAIL ⇔ 无任何候选;INCONCLUSIVE ⇔ 存在候选但全部被脉冲污染
(或数值不可判定,此处不预期)。

**预测(先于运行的手算)**:
- C1:PASS(定理 1;极大在 x\*≈1.0)。
- C2:fp ≈ μ(x\*)·[tanh S_E − w_EI·tanh S_I]/(1−λ_E),μ(x\*)=(3+x\*)/5 ∈ [0.64,1.2],
  S_E = 0.8x\*−0.6, S_I = 0.8x\*−0.9。差项两端都→1 − 0.8·1 = 0.2(饱和),中部存在极浅平台峰
  (手算:fp 峰值 ≈0.56 @ x\*≈2.0,向 x\*=3.0 仅回落 ≈0.023;对应二阶差分 |Δ²|≈1e-4,
  远低于预注册曲率容差 tol_c=2e-3)→ 预测:**无严格局部极大(FAIL)**,曲线为"爬升—平台"。
- C3:fp ≈ [tanh S_E·C_E − w_EI·tanh S_I·μ]/(1−λ_E),C_E→x\*(探针主导)→ 随 x\* 单调增,
  预计直到脉冲起始区都单调增;预测:**无局部极大,上部进入脉冲区**。
- C4:fp ≈ [tanh S_E·C_E − w_EI·tanh S_I·C_I]/(1−λ_E),C_E≈C_I≈x\*(探针主导),
  差项 ≈ x\*·(tanh S_E − 0.8·tanh S_I)/0.5,两 tanh 均单调增且差>0 → 预测:**单调增、无局部极大**;
  全程亚阈值(估计 fp≤1.4 < 3.0)。手算核对表附后。

> 关键点:C1 的 PASS 是"对手阈值结构"的证明结论;若 C2–C4 无极大,则说明
> 惊奇门与标量注意力**没有**把单调驱动变成带通——带通需要的是阈值对手结构(静态),而非动态注意力。
> 这一负结果本身即机制信息(消融阶梯的意义)。若运行结果与预测不符,以数据为准并如实报告。

## 6. 主判据 P2 与次级指标(规范 §16、§19、§20)

### 6.1 反事实查询实验
固定 X\* 内容与布局,分别以查询振幅 Q_A=3.0、Q_B=4.0 作为探针 tap 输入(> 全部历史内容)。
测量:
- 查询敏感性: R(Q_A) ≠ R(Q_B)?(R = 条件固定点 h_E\*;报告差值)
- FlipRate = P[argmax_i α_i^E(Q_A) ≠ argmax_i α_i^E(Q_B)]:
  变体 P2a:argmax 仅在历史候选槽 {A,B} 上(不含探针槽);
  变体 P2b:argmax 在全部 5 个窗口槽上。
  平局(α 均匀,S=0)不进入分母,单独报告。
- 集合:6 种布局;每布局确定性 ⇒ FlipRate ∈ {0,1,∅}。
- 预测:FlipRate = 0(引理 3);同时 R 随 Q 增大(R(Q_B)>R(Q_A),振幅敏感性存在)。
- **诚实表述规则**:FlipRate=0 ⇒ "E-I 竞争产生(或未产生)选择性调谐,但未突破 TAN-I 的
  标量查询条件化边界"——禁止声称任何路由/绑定。

### 6.2 P2 适用范围(预注册)
C1:无窗口注意力、无候选槽结构 → P2 N/A(记录)。
C2:α 强制均匀、无唯一 argmax → P2 N/A(记录;无注意力的对照不可用于路由问题)。
C3、C4:执行 P2a/P2b。

### 6.3 次级指标(预注册定义;在 h_E\* 曲线上计算,脉冲区以独立报告处理)
1. 选择性指数 SI = (R_max − R_min)/(R_max + R_min + 1e-9)(全扫描范围;注明是否受脉冲影响)。
2. FWHM:主峰半高全宽(线性插值到 (R_max+R_min)/2;若主峰不成立→ None + 原因)。
3. 峰位置 x_peak:最大候选的网格位置(±δ/2;报告网格点与局部二次插值)。
4. 峰后抑制斜率:峰后第一个连续亚阈值 5 步的最小二乘斜率(报告步数与 R²)。
5. 最大抑制幅度:R_max − min{R(x\*) : x\* ∈ (x_peak, 3.0]}(亚阈值段)。
6. 条件固定点 h_E\*、h_I\*(每网格点,JSON 含曲线)。
